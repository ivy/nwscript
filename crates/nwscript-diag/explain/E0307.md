A function is called, or a global used, above its declaration. NWScript reads a file from top to bottom, and a name exists from its declaration on; includes count as the text they stand for.

Declare a prototype (the function's header followed by `;`) above the first call, or move the definition up.

```c
void main()
{
    Greet(GetFirstPC());
}

void Greet(object oPC)
{
    SpeakString("Hello");
}
```

```c
void Greet(object oPC);

void main()
{
    Greet(GetFirstPC());
}

void Greet(object oPC)
{
    SpeakString("Hello");
}
```
