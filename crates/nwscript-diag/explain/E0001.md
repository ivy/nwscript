An input file could not be read.

The path named in the diagnostic does not exist, is not a file, or cannot be opened by the current user. Every input `nws` reads is named on the command line or found through an include directory, so the path in the message is the one to check.

```text
$ nws check missing.nss
error[E0001]: cannot read `missing.nss`: No such file or directory
```

Check the spelling and the working directory, or pass the file's full path.
