One argument of a call changes a variable that another argument of the same call reads. NWScript evaluates arguments from last to first, which most readers do not expect, so the call's meaning depends on an ordering that is easy to misread.

```c
Foo(n++, n);              // warning[W0006]: the second argument is evaluated first
```

Fixed:

```c
int nOld = n;
n = n + 1;
Foo(nOld, n);
```

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0006`, or on one line with a comment `// nwscript: allow(W0006)` at the end of the line or alone on the line before it.
