The program size record after the header is missing, or the length it declares is not the file's length.

Offset 8 of an NCS file holds the byte `0x42` and offsets 9 to 12 the file's total length in bytes, big-endian. The engine and the decoder rely on it. A size that is larger than the file means the file was cut short (that case is reported as E0105); a size that is smaller means bytes were appended after the program, or the record was written by a tool that computed it differently.

```text
error[E0102]: the size record declares 120 bytes but the file has 128
```

Recompile the script, or re-extract the file from its archive. If a tool you wrote produced the file, write the record as `0x42` followed by the total file length.
