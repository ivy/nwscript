A `struct` type is named above the declaration of the struct, in a prototype, a global or a function, where the language reads top to bottom.

```c
struct List MakeList();          // error[E0327]: used above its declaration
struct List { int nCount; };
void main() { }
```

Fixed:

```c
struct List { int nCount; };
struct List MakeList();
void main() { }
```

nwnnsscomp accepts the first form, and the Ebon Hawk party conversations mod's `k_inc_ehbanter.nss` uses it, so `--compat nwnnsscomp` and `--compat bioware` accept it as a warning. The type means the same either way.
