The script's entry point is malformed. A script is run through one of two functions: `void main()`, which the engine runs from a trigger, a creature's event or `ExecuteScript`, and `int StartingConditional()`, which a dialogue runs to decide whether a line is available. Neither takes parameters, each has a body, and a script has one or the other, not both.

A file with neither is a library, such as an include file; it is checked, but there is nothing to run.

```c
int main()
{
    return 1;
}
```

```c
int StartingConditional()
{
    return 1;
}
```
