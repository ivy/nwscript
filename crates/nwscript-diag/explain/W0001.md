A local variable is declared and perhaps assigned, but its value is never read.

```c
int nUnused = GetHitDice(OBJECT_SELF);   // warning[W0001]
```

Fixed:

```c
int nLevel = GetHitDice(OBJECT_SELF);
if (nLevel > 5) { ... }                    // read: fine
```

An assignment alone does not count as a use. A call in the initialiser still runs, so remove the variable but keep the call if its effect matters.

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0001`, or on one line with a comment `// nwscript: allow(W0001)` at the end of the line or alone on the line before it.
