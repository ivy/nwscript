A string literal has no closing `"` on its line.

A string literal starts and ends with `"` on the same line; it cannot span lines. The compiler ends the literal at the line end and reports this error, so the next line is still read as code.

```text
void main() {
    SpeakString("Hello there);
}
```

Add the closing `"`. To build a long string, concatenate shorter ones with `+`.
