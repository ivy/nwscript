An `#include` names a file that cannot be found or read.

The name is a resource name, without the `.nss` extension, and is matched ignoring case. It is searched for in the script's own directory, then in each `-I` directory in the order given.

```c
#include "k_inc_utilty"

void main()
{
}
```

```c
#include "k_inc_utility"

void main()
{
}
// file: k_inc_utility.nss
int UT_TRUE = 1;
```

KotOR's own includes (`k_inc_generic`, `k_inc_utility` and the rest) are in `scripts.bif`; extract them beside your script or pass their directory with `-I`.
