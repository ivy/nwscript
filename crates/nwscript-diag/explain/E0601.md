The decompiler found no entry point it recognises. Every script BioWare's compiler and nwnnsscomp produce starts with a stub that calls the entry point and returns: `JSR` then `RETN`, or `RSADDI`, `JSR`, `RETN` for a `StartingConditional`. Bytecode that starts otherwise was written by hand or by another tool, or is not a compiled script at all.

```text
$ nws --nwscript nwscript.nss decompile odd.ncs
error[E0601]: odd.ncs: the program does not start with an entry stub (`JSR`, `RETN`)
```

Disassemble the file (`nws disasm`) to see what it holds; the disassembly round-trips through `nws asm` whatever its shape.
