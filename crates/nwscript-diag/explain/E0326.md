An argument for a parameter of type `action` is not a call to a function that returns `void`.

`DelayCommand`, `AssignCommand` and `ActionDoCommand` take an action: a call that the engine stores, with the values on the stack at that moment, and runs later. The argument must be a call, and the call must return nothing, because nothing is there to receive its value.

```c
void main()
{
    DelayCommand(2.0, GetIsObjectValid(OBJECT_SELF));
}
```

```c
void Check()
{
    if (!GetIsObjectValid(OBJECT_SELF))
        SpeakString("gone");
}

void main()
{
    DelayCommand(2.0, Check());
}
```
