An instruction starts with a byte that is not an NCS opcode.

NCS opcodes are the bytes `0x01` to `0x2D`. Any other byte where an instruction should start means the file is damaged, or that an earlier instruction was decoded with the wrong length, which happens when the bytes were produced by a tool that does not follow the format. The decoder stops rather than guess where the next instruction begins.

```text
error[E0103]: unknown opcode 0x7F at offset 211
```

Re-extract or recompile the file. If it was produced by another compiler, compare its bytes around the reported offset with the instruction before it.
