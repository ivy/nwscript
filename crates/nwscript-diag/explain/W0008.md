Arithmetic (`+ - * /`) mixes an `int` and a `float`, so the `int` is converted to `float` before the operation. NWScript has no other implicit conversion (a comparison of an `int` with a `float` is an error), and this one is easy to miss when it changes the result, as in `nCount / 2.0`.

```c
float fHalf = nCount / 2.0;     // warning[W0008]
```

Fixed:

```c
float fHalf = IntToFloat(nCount) / 2.0;
```

The conversion is exact for every `int` a script is likely to hold; the warning is about saying it.

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0008`, or on one line with a comment `// nwscript: allow(W0008)` at the end of the line or alone on the line before it.
