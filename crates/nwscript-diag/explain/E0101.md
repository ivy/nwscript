The file is not compiled NWScript bytecode.

Every NCS file starts with the eight ASCII bytes `NCS V1.0`. The bytes at the start of this file are something else: often an NSS source file passed where a compiled script was expected, a resource extracted under the wrong type, or a file from another game's format.

```text
$ nws disasm k_ai_master.nss
error[E0101]: not an NCS V1.0 file
```

Pass the compiled `.ncs` file, or compile the source first.
