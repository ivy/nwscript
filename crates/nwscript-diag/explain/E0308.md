A call to an engine routine gives more arguments than its declaration in `nwscript.nss` has parameters, or leaves out one that has no default.

```c
void main()
{
    AddPartyMember(GetObjectByTag("bastila"));
}
```

```c
void main()
{
    AddPartyMember(NPC_BASTILA, GetObjectByTag("bastila"));
}
```

BioWare's compiler accepted the first form: `k_act_bastadd.nss` calls `AddPartyMember` with one argument, and its NCS calls routine 569 with one, because BioWare compiled it against an `nwscript.nss` that did not ship. `--compat bioware` accepts the error for that reason, and the call is compiled with the arguments as written. Anywhere else it is a mistake: give the arguments the shipped declaration lists (`nws fn NAME` prints it).
