An expression statement computes a value and throws it away: it has no call, assignment or increment, so it does nothing. Usually it is a comparison meant as an assignment.

```c
nHP == 1;                 // warning[W0007]
```

Fixed:

```c
nHP = 1;
```

Five of KotOR 1's own scripts have such statements.

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0007`, or on one line with a comment `// nwscript: allow(W0007)` at the end of the line or alone on the line before it.
