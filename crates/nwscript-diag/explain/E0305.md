A value has a different type from the one its place requires: an argument to a script function, the value assigned to a variable, an initialiser, a `return` value, a condition, or an operand.

NWScript converts no value implicitly, not even an `int` to a `float`. Convert with an engine routine (`IntToFloat`, `FloatToInt`, `IntToString`, `StringToInt`, `FloatToString`), or write the literal in the type required (`1.0` rather than `1`). An operator applies to the types the bytecode has an instruction for: `+` adds an `int` and a `float` in any mix, but `<` compares two `int`s or two `float`s, never one of each.

```c
void main()
{
    float fDelay = 2;
    string sCount = 3;
}
```

```c
void main()
{
    float fDelay = 2.0;
    string sCount = IntToString(3);
}
```

An argument of the wrong type to an engine routine is `E0309`.
