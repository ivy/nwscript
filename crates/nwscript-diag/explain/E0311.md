A function's definition returns a different type from the one its prototype declares.

```c
void PlayTakeOff(int nPlanet);

string PlayTakeOff(int nPlanet)
{
    return "NULL";
}
```

```c
string PlayTakeOff(int nPlanet);

string PlayTakeOff(int nPlanet)
{
    return "NULL";
}
```

BioWare's compiler accepted this: `k_inc_ebonhawk.nss` declares `EBO_PlayTakeOff` and `EBO_PlayLanding` as `void` and defines them as `string`, and five vanilla scripts include it. `--compat bioware` accepts the error for that reason, and the function has the definition's type. Anywhere else make the two agree.
