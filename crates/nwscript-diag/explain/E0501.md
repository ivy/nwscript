The interpreter stopped because the bytecode did something its machine cannot: popped an empty stack, read a value of the wrong type, jumped where no instruction starts, called an engine routine the table does not have, or used an instruction the interpreter does not run.

For bytecode a compiler produced from valid source this is a bug in the compiler or in the interpreter; the diagnostic points at the instruction's offset in the file.

```text
$ nws --game k1 --nwscript nwscript.nss run broken.ncs
error[E0501]: at offset 33: stack underflow
```

Disassemble the file (`nws disasm --raw`) and read the instructions before that offset. If the bytecode is BioWare's or came from a compiler you trust, please report it with the file.
