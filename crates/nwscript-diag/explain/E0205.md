The parser expected one thing and found another.

The message names what the grammar allows at that point and what is there instead: a missing `;` at the end of a statement, a missing `)` or `}`, a statement where a declaration was expected, a token that begins no expression. The parser then resumes at the next point it can recognise (a `;`, a `}`, the next declaration), so one mistake produces one error and the rest of the file is still checked.

```text
void main() {
    int nGold = GetGold()
    GiveGoldToCreature(OBJECT_SELF, nGold);
}
```

```text
error[E0205]: expected `;`, found identifier `GiveGoldToCreature`
```

Insert what was expected, usually at the end of the line before the one the error points to, or remove the stray token. The grammar the parser follows is `docs/grammar.md` in the nwscript repository.
