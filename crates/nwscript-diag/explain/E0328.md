Two `case` labels in one `switch` have the same value, so the second can never be reached by its value. Constants are compared by value, so two names with the same value collide too.

```c
void main()
{
    int n = 1;
    switch (n)
    {
        case 1:
        case 2:
        case 1:              // error[E0328]
            break;
    }
}
```

Fixed: remove the repeated label.

```c
void main()
{
    int n = 1;
    switch (n)
    {
        case 1:
        case 2:
            break;
    }
}
```

nwnnsscomp accepts a repeated label, and the KotOR Community Patch's `cp_inc_k1.nss` has one (`BASE_ITEM_SONIC_PISTOL` twice), so `--compat nwnnsscomp` and `--compat bioware` accept it as a warning.
