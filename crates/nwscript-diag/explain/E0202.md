A block comment opens with `/*` and never closes.

Block comments run from `/*` to the first `*/` after it and do not nest. When no `*/` follows, the comment would swallow the rest of the file; instead the compiler reports this error and ends the comment at the end of its line, so the declarations after it are still checked.

```text
/* Spawn the guards
void main() {
    SpawnGuards();
}
```

Close the comment with `*/` where it should end, or, for a comment that fits on one line, start it with `//` instead.
