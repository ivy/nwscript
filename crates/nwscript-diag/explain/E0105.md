The NCS file ends before the data it declares.

Either the file ends inside its 13-byte header, or inside an instruction's operands, or before the length its program size record declares. The file was most likely cut short while being copied, downloaded or extracted.

```text
error[E0105]: instruction at offset 1022 needs 8 bytes, but the file ends at offset 1026
```

Extract or copy the file again from its source. The size record at offset 9 gives the length the complete file has.
