A name is used as a value, but nothing by that name is declared: no local variable or parameter in scope, no global in the script or its includes, and no constant in `nwscript.nss`.

Names are case-sensitive, and a local is visible only inside the block that declares it, after its declaration.

```c
void main()
{
    int nGold = GetGold(OBJECT_SELF);
    if (nGlod > 100)
        SpeakString("rich");
}
```

```c
void main()
{
    int nGold = GetGold(OBJECT_SELF);
    if (nGold > 100)
        SpeakString("rich");
}
```

The diagnostic suggests the nearest name it knows. A constant from another game, such as a Neverwinter Nights `VFX_` constant, is not in KotOR's `nwscript.nss`; use KotOR's own constant or its value.
