A statement follows a `return`, `break` or `continue` in the same block, so nothing can reach it.

```c
return TRUE;
PrintString("never");   // warning[W0005]
```

Fixed:

```c
PrintString("first");
return TRUE;
```

A `case` or `default` label starts reachable code again. BioWare's compiler still emits unreachable statements, so this is about the source, not the bytecode.

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0005`, or on one line with a comment `// nwscript: allow(W0005)` at the end of the line or alone on the line before it.
