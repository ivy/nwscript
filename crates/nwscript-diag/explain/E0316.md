A function that returns a value can reach the end of its body without a `return`.

The rule is the one BioWare's language uses, and it is simple: a body returns when it holds a `return`, or a block that does, or an `if` whose two branches both do. A loop or a `switch` never counts, even with a `return` in every case, so a function ending in one needs a `return` after it.

```c
int StartingConditional()
{
    switch (GetGlobalNumber("K_STATE"))
    {
        case 1: return TRUE;
        default: return FALSE;
    }
}
```

```c
int StartingConditional()
{
    switch (GetGlobalNumber("K_STATE"))
    {
        case 1: return TRUE;
    }
    return FALSE;
}
```
