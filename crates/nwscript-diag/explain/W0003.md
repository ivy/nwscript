A function defined in the script is never called from its entry point, directly or through other functions.

```c
void Unused() { }        // warning[W0003]
void main() { }
```

Fixed:

```c
void main() { Helper(); }   // called: fine
```

Include files are libraries and are not checked for this; a script with neither `main` nor `StartingConditional` is not either. The compiler does not emit an uncalled function, so this costs nothing at run time, but it is often a sign of a call that was meant and is missing.

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0003`, or on one line with a comment `// nwscript: allow(W0003)` at the end of the line or alone on the line before it.
