A declaration stands where the language has none: a struct declared inside a function, or an initialiser on a struct field.

Structs are declared at the top level of a file, and a field gets its value by assignment to a variable of the struct type.

```c
void main()
{
    struct Pair { int a; int b; };
}
```

```c
struct Pair { int a; int b; };

void main()
{
    struct Pair p;
    p.a = 1;
}
```
