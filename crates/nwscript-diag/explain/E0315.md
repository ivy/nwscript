A `case` or `default` label is malformed: its value is not an integer constant, two labels have the same value, a switch has two `default`s, or a label stands outside the braces of a `switch`.

A `case` value is an integer literal, a negated one, or an `int` constant from `nwscript.nss` such as `FORCE_POWER_CHOKE`. A script's own globals are variables, even when initialised with a literal, and an expression such as `1 + 2` is not a label.

```c
int SPAWN_GUARD = 1;

void main()
{
    switch (GetGlobalNumber("K_SPAWN"))
    {
        case SPAWN_GUARD:
            SpeakString("guard");
            break;
    }
}
```

```c
void main()
{
    switch (GetGlobalNumber("K_SPAWN"))
    {
        case 1:
            SpeakString("guard");
            break;
    }
}
```
