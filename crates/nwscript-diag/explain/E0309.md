An argument to an engine routine has a different type from the parameter its declaration in `nwscript.nss` gives.

NWScript converts no value implicitly; convert it with an engine routine such as `IntToFloat` or `IntToString`, or pass a value of the declared type.

```c
void main()
{
    RemovePartyMember(GetObjectByTag("bastila"));
}
```

```c
void main()
{
    RemovePartyMember(NPC_BASTILA);
}
```

BioWare's compiler accepted the first form in nine vanilla scripts (`k_act_bastrmv.nss` and its siblings) because it compiled them against an `nwscript.nss` that did not ship, in which these routines took an object. `--compat bioware` accepts the error for that reason, and the call is compiled with the arguments as written. Anywhere else it is a mistake.
