The entry point reaches a call to a function that has a prototype but no definition anywhere in the script or its includes, so there is no code to call.

```c
void Greet(object oPC);

void main()
{
    Greet(GetFirstPC());
}
```

```c
void Greet(object oPC);

void main()
{
    Greet(GetFirstPC());
}

void Greet(object oPC)
{
    SpeakString("Hello");
}
```

A library that declares functions it does not define is not an error until a script calls them.
