An assignment, compound assignment, `++` or `--` has something on its left that is not a variable: a call, a literal, a constant, or an expression.

Only a local, a parameter, a global, a struct field of one, or a vector component of one can be stored to. Constants from `nwscript.nss`, such as `TRUE`, are values, not variables.

```c
void main()
{
    GetGlobalNumber("K_COUNT") = 1;
}
```

```c
void main()
{
    SetGlobalNumber("K_COUNT", 1);
}
```
