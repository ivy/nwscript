A name is declared twice where it must be unique: two locals in one block, two globals, two definitions of one function, two structs or two fields of one struct with the same name, or a global or function with the name of a constant or routine from `nwscript.nss`.

A local in a nested block may reuse an outer name; it hides the outer one until the block ends.

```c
void main()
{
    int nCount = 0;
    int nCount = 1;
}
```

```c
void main()
{
    int nCount = 0;
    nCount = 1;
}
```

Two includes that define the same function cannot both be included; include one of them.
