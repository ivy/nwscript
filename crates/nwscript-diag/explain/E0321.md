A `.` names a member its value does not have. A struct has the fields its declaration lists; a `vector` has `x`, `y` and `z`, each a `float`; no other type has members.

```c
void main()
{
    vector vPos = GetPosition(OBJECT_SELF);
    float fHeight = vPos.height;
}
```

```c
void main()
{
    vector vPos = GetPosition(OBJECT_SELF);
    float fHeight = vPos.z;
}
```
