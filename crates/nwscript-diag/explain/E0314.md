`break` stands outside every loop and `switch`, or `continue` outside every loop. There is nothing for it to leave.

```c
void main()
{
    if (GetGlobalNumber("K_DONE"))
        break;
    SetGlobalNumber("K_DONE", 1);
}
```

```c
void main()
{
    if (GetGlobalNumber("K_DONE"))
        return;
    SetGlobalNumber("K_DONE", 1);
}
```
