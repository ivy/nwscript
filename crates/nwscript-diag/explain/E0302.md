A constant's initialiser, or a parameter's default, is not a value known before the program runs.

`nwscript.nss` declares its constants and the defaults of engine routines with literals (`1`, `-1`, `0.0`, `"text"`), the names of constants declared earlier in the file, `OBJECT_SELF`, `OBJECT_INVALID`, or a vector of number literals such as `[0.0, 0.0, 0.0]`. An expression of any other kind, or a name not yet declared, cannot be read as a constant.

```c
int A = B + 1;          // error[E0302]: an expression
int B = 1;
int A = B;              // fine once B is declared above it
```
