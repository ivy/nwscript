The declarations of one function, a prototype and its definition or two prototypes, disagree on its parameters: their number or their types, or two prototypes on the return type.

```c
void Reward(object oPC, int nGold);

void Reward(object oPC, float fGold)
{
}
```

```c
void Reward(object oPC, int nGold);

void Reward(object oPC, int nGold)
{
}
```

Defaults may differ between a prototype and the definition; a call uses the prototype's.
