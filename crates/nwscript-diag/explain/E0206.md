A directive is unknown, malformed, or in the wrong place.

NWScript has two directives, each a whole line starting with `#`: `#include "name"`, which names another script by resource name without its extension, and `#define NAME value`, which `nwscript.nss` uses to name the engine structure types. A directive must be the first thing on its line and must sit at top level, outside any function. There is no `#if`, `#ifdef` or `#pragma`, and an `#include` takes nothing after its quoted name.

```text
#include <k_inc_debug>
void main() { #include "k_inc_utility" }
```

Write `#include "k_inc_debug"` on a line of its own, before the file's declarations, and remove any other directive.
