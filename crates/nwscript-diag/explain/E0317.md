A `return` disagrees with its function's type: it has a value in a `void` function, or none in a function that returns a value.

```c
void main()
{
    if (GetIsObjectValid(GetFirstPC()))
        return TRUE;
}
```

```c
void main()
{
    if (GetIsObjectValid(GetFirstPC()))
        return;
}
```

A value of the wrong type is `E0305`.
