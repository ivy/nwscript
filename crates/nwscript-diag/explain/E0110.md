An assembly line names an instruction NCS does not have.

Mnemonics carry the type suffix their type byte selects, as the disassembler prints them: `CONSTI`, `CONSTS`, `EQUALFF`, `RSADDE2`, `ADDIF`. A bare opcode name such as `CONST` or `EQUAL` is not enough, because the suffix decides the type byte and the operands.

```text
    CONST 5        ; error[E0110]: unknown instruction `CONST`
    CONSTI 5       ; the integer form
```

`docs/asm.md` lists every mnemonic.
