A declaration names a type that does not exist.

NWScript's types are `void`, `int`, `float`, `string`, `object`, `vector` and `action`, `struct NAME` for a script's structures, and the engine structures `nwscript.nss` defines with `#define ENGINE_STRUCTURE_n NAME` (`effect`, `event`, `location` and `talent` in KotOR 1). Type names are case-sensitive.

KotOR 1's own `nwscript.nss` has one at line 5145:

```c
void SetAvailableNPCId(INT nNPC, OBJECT_ID oidNPC);   // error[E0301]
void SetAvailableNPCId(int nNPC, object oidNPC);      // what it means
```

When reading `nwscript.nss`, the function keeps its number, since engine routines are numbered by their position, and its signature is recovered from the names: a type in another case, or the type a name starts with.
