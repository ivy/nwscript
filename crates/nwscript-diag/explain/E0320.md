An include file includes itself, directly or through other includes. A file's declarations reach a script once; an include reached a second time along a different chain is skipped, but a chain that returns to a file it is inside cannot be read.

```c
#include "k_inc_a"

void main()
{
}
// file: k_inc_a.nss
#include "k_inc_b"
// file: k_inc_b.nss
#include "k_inc_a"
```

```c
#include "k_inc_a"

void main()
{
}
// file: k_inc_a.nss
#include "k_inc_b"
// file: k_inc_b.nss
int B_VALUE = 1;
```

Move what both files need into a third that each includes, or remove the `#include` that closes the loop.
