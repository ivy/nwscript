A call names a function that is declared nowhere: not in the script, not in its includes, and not among the engine routines of `nwscript.nss`.

Function names are case-sensitive. A function from an include is visible only when the script includes that file. Neverwinter Nights routines such as `SetLocalInt` do not exist in KotOR.

```c
void main()
{
    object oDoor = GetObjectByTag("tar_door");
    SetLocked(oDoor, FALSE);
    UT_Unlock(oDoor);
}
```

```c
void UT_Unlock(object oDoor)
{
    SetLocked(oDoor, FALSE);
}

void main()
{
    object oDoor = GetObjectByTag("tar_door");
    UT_Unlock(oDoor);
}
```

`nws fn --grep PATTERN` searches the engine's routines by name.
