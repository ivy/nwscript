Statements and expressions are nested more deeply than the parser allows.

The parser accepts up to 256 levels of nesting, counting each statement inside another (a block in an `if` in a `while`) and each operand inside an expression (parentheses, operators, call arguments) together. No hand-written script comes near it; input that does is usually generated or damaged. The parser reports the first place the limit is passed, skips what lies beyond it, and checks the rest of the file.

```text
void main() {
    int n = ((((((((((((((((((((/* ...hundreds more... */ 1;
}
```

Split the expression into several statements with intermediate variables, or move deeply nested blocks into functions of their own.
