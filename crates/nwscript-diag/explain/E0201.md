A character in the source begins no token.

NWScript source is single-byte text. Outside comments and string literals it uses only letters, digits, `_`, whitespace and the language's punctuators; a byte above 0x7F (an accented letter or a typographic quote pasted from a word processor) or a character such as `@`, `$` or a backtick is not part of the language. The lexer skips the character and reports it here, and the rest of the file is still checked.

```text
void main() {
    int n = 3 @;
}
```

```text
error[E0201]: unexpected character
```

Delete the character, or move it into a `//` comment. If it is a curly quote around a string, replace it with a plain `"`.
