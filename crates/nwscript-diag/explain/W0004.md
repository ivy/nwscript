A local variable has the name of a parameter, of a local in an enclosing block, or of a global. After its declaration the name means the new local, and the other value can no longer be reached by name.

```c
int GetPower(int nDroid = FALSE)
{
    int nDroid = 0;            // warning[W0004]
    return nDroid;             // always the local
}
```

Fixed:

```c
int GetPower(int nDroid = FALSE)
{
    int nCount = 0;
    return nDroid + nCount;
}
```

KotOR 1's own `k_inc_gensupport.nss` has one: `GN_GetTargetedForcePower`'s local `nDroid` hides its parameter, so every test of `nDroid` reads the local.

Lints are errors by default and warnings under `--compat`. Allow one with `--allow W0004`, or on one line with a comment `// nwscript: allow(W0004)` at the end of the line or alone on the line before it.
