A call to a function the script declares gives more arguments than it has parameters, or leaves out one that has no default.

A call may omit trailing arguments whose parameters have defaults, and only those.

```c
void Reward(object oPC, int nGold, int nXP = 0)
{
    GiveGoldToCreature(oPC, nGold);
}

void main()
{
    Reward(GetFirstPC());
}
```

```c
void Reward(object oPC, int nGold, int nXP = 0)
{
    GiveGoldToCreature(oPC, nGold);
}

void main()
{
    Reward(GetFirstPC(), 100);
}
```

The same mistake in a call to an engine routine is `E0308`.
