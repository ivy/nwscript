A type stands where it cannot: a variable, field or parameter of type `void`, a parameter of type `action` in a script's function, or a function that returns `action`.

`action` is the type of the deferred call that engine routines such as `DelayCommand`, `AssignCommand` and `ActionDoCommand` take; a script's own functions cannot take or return one.

```c
void Later(action aDo)
{
    DelayCommand(1.0, aDo);
}

void main()
{
}
```

```c
void Later(string sLine)
{
    DelayCommand(1.0, SpeakString(sLine));
}

void main()
{
}
```
