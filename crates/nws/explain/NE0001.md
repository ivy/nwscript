The install `--game-dir` names holds no `nwscript.nss`, and no directory searched before it has one either.

With `--game-dir DIR`, includes and `nwscript.nss` that the script's own directory and the `-I` directories lack are read from the install at `DIR`, in the order the game loads them: `Override/`, the capsules of the module `--module` names, KotOR 1's `patch.erf`, then the BIFs `chitin.key` indexes. A vanilla install carries `nwscript.nss` in `scripts.bif`; an install this error names has had it removed from the KEY and the BIFs, or `DIR` is some other folder that happens to hold a `chitin.key`.

```text
$ nws --game k1 --game-dir ~/games/not-kotor compile k_my_script.nss
error[NE0001]: no nwscript.nss in the install at `~/games/not-kotor`
```

Check the folder with `rakata which nwscript.nss --game DIR`, point `--game-dir` at the folder holding the game's `chitin.key`, or supply the file another way: `--nwscript FILE`, or `-I` a directory that holds it.
