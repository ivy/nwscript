A walkmesh type that is neither an object's nor an area room's.

The 32-bit field at offset 8 of a walkmesh is 1 in every vanilla WOK (an area room's, in the area's frame) and 0 in every vanilla PWK and DWK (a placeable's or a door's, in the object's own frame). The file read has another value.

```text
error[RE2503]: walkmesh type 2 is neither 0 (a placeable's or door's) nor 1 (an area room's)
```

The file is a variant this crate has not measured, or its header is damaged. A tool that wrote it should write 1 for a room and 0 for a placeable or door.
