A dialogue that several modules hold, with no module named, and that no global layer holds or only `Override/` does.

Without `--module`, `rakata dialog` looks for `NAME.dlg` in `Override/`, `patch.erf` and the BIFs, then in every module's capsules. When no global layer holds it and exactly one module does, that module is used and its scripts are searched too. `dialog show` does the same for a dialogue that of the global layers only `Override/` holds: a mod's copy of a module's dialogue, which the engine loads in each module holding the name. When several modules hold it, which one is meant is the user's choice: the copies may differ, and each module's scripts are its own.

```text
error[RE1105]: k_hen_dialog.dlg is in no global layer and in 2 modules: danm13, danm14aa; name one with --module
error[RE1105]: k_hen_dialog.dlg is in Override/ and in 2 modules: danm13, danm14aa; name one with --module
```

Pass `--module STEM` with one of the modules named.
