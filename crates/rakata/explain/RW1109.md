A condition that computes the name of the global it reads.

The condition calls a `GetGlobal*` routine with a name that is neither a string literal nor a literal with a computed part appended, so which global it reads, and whether `globalcat.2da` declares it, cannot be known from the bytecode. A name built on a literal (`"OAJ_DOWN_" + IntToString(n)`) is checked as a family instead: some declared global must begin with that literal, and when none does the finding is RW1106. With no `globalcat.2da` to ask, such a family is reported here.

```text
warning[RW1109]: d.dlg the start into E0 (index:E0 (fragile)) has the condition k_con_name, which passes a computed name to GetGlobalBoolean, so the global it reads cannot be checked
```

This is not a fault, only a read the lint cannot follow; check the script's source by hand. The vanilla game has none: its one computed read, `k_pman_flow05`'s `"MAN_WATER_" + sParam1`, is a family `globalcat.2da` declares.
