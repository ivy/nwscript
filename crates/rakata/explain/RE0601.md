Not a GFF V3.2 file.

A GFF begins with a four-byte file type (`UTC `, `DLG `, `GIT `, with a trailing space) and the four bytes `V3.2`. These bytes have another version, or are something else: a file saved under a GFF extension that is not one, or a member of an archive whose type id lies.

```text
error[RE0601]: not a GFF V3.2 file: the file begins `RIM V1.0`
```

Check what the file is with its first eight bytes. Every GFF KotOR 1 and 2 ship is `V3.2`; a `V3.3` or `V4.0` file comes from a later BioWare engine and this toolset does not read it.
