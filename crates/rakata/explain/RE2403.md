A mesh's vertices lie past the end of the MDX.

Each mesh of a binary model keeps its vertices in the MDX beside the MDL: a block of `vertex count × stride` bytes at an offset the mesh header gives. The block of the mesh named lies past the end of the MDX given. The MDX is another model's, cut short, or missing (an empty MDX was passed for a model whose meshes need one).

```text
error[RE2403]: mesh `floor`'s vertices at MDX offset 12000 need 1600 bytes and the MDX has 8000
```

Pass the MDX of the same resref as the MDL. For a model in a RIM, the MDX is in the RIM's `dx` partner (`global.rim` and `globaldx.rim`).
