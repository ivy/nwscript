A Lua script that raised an error without a code, or did not load.

The script stopped on an error that is not one of the façade's: a syntax error, a call on `nil`, an `error("...")` of the script's own, or a value of the wrong type handed to a function where Lua's own conversion caught it. Errors from the façade keep their own codes (an authoring refusal is `RE14xx`, a missing resource `RE0404`), so this code means the cause is in the script.

```text
error[RE1804]: build.lua:12: attempt to index a nil value (local 'row')
```

The message names the file and line; the traceback in the note shows the calls that led there.
