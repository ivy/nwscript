A GFF too large for 32-bit offsets.

Every offset and count in a GFF header is a 32-bit word, so a file cannot exceed four gigabytes. The tree being written would.

```text
error[RE0605]: a GFF of 4521000000 bytes exceeds the format's 32-bit offsets
```

No file the game loads comes near this; the tree holds something that does not belong in a GFF, a `Void` field of a whole archive for instance.
