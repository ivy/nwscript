A dialogue node whose script is not the one an edit replaces.

An edit that changes the script one of the game's nodes runs names the script it expects there. A different script means another mod has already changed the node, or the key names another node than the edit was written for; replacing it would drop that change without a word.

```text
error[RE1416]: tar03_cand031.dlg's node R35 runs `k_ptar_other`, not `k_ptar_davikest`, the script the edit replaces
```

Find the node again in the dialogue as the install loads it (`rakata dialog show`), and update the key or the expected script.
