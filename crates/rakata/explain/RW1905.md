Resources the lint could not read, so what they name is unchecked.

A GFF, 2DA or script, or an archive holding them, did not read: its references could not be checked, so a reference it makes to nothing is not reported. The message counts them and names the first few with the reader's error, whose code `rakata explain` covers.

```text
warning[RW1905]: 2 resources did not read, so what they name is not checked: `Override/broken.utc` (RE0602: ...)
```

With `--db`, these are the index's `failed` coverage rows. A file the engine accepts and the reader refuses is a defect in the reader; `rakata conformance` over the tree shows every such file.
