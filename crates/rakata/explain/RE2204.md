A TGA truncated before its header or pixels end.

A TGA is an 18-byte header, an image id and a colour map whose lengths the header gives, then the pixels: width × height of them, raw or in run-length packets. The file read ends before the header does, before the id and colour map do, or before the last pixel.

```text
error[RE2204]: the TGA's pixels needs 16384 bytes and the file has 9000
```

The file was cut short in copying or extraction. Re-extract it from its archive (the game's lightmaps are in `data/lightmaps*.bif`), or save the image again.
