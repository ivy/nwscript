An archive too large for 32-bit offsets.

Every archive format stores member offsets and lengths as unsigned 32-bit numbers, so an archive cannot exceed 4 GiB. The members given would make one that does.

```text
error[RE0205]: an archive of 4312000000 bytes exceeds the format's 32-bit offsets
```

Split the members over more than one archive. The largest file BioWare shipped, the `swpc_tex_tpa.erf` texture pack, is 400 MB.
