A supermodel that is not found, ending the chain.

A model names a supermodel in its header, whose animations it plays for any name it has none of, and which names its own in turn. `rakata mdl show` looks each one up by name: through the install with `--game`, as the engine does, and else beside the model, in its folder or archive. The supermodel named was found neither way, so the chain ends before it and the animations it would give are not listed.

```text
warning[RW1303]: the supermodel `s_female03` is not found: the chain ends before it, and what it would give is not shown
  = help: a supermodel is found through the install: name it with --game DIR
```

Name the install with `--game DIR`, or put the supermodel's MDL and MDX beside the model. A few vanilla models name a supermodel the game does not ship; for those the warning is the game's own state.
