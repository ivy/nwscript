A reordering that is not a permutation of the list.

Reordering a dialogue's `EntryList` or `ReplyList` takes the new order as the old index of each node, in its new place: every index of the list, from 0, exactly once. Every link and start into the list is rewritten to follow its node. An order that repeats an index, leaves one out, or names one past the end would lose or duplicate a node, so nothing is changed.

```text
error[RE1107]: banter.dlg: a new order for EntryList names each of its 12 indices once, from 0
```

Reordering moves indices that scripts and other mods' changes may rely on; append instead unless the order itself is the point.
