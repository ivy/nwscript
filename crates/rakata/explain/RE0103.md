A file extension that names no resource type.

The resource type table maps each extension the games use to the numeric type id their archives store: `.ncs`, `.dlg`, `.utc`, `.2da`, `.tlk`, `.tpc` and the rest of BioWare's table with the types KotOR 1 and 2 added. An extension outside it cannot be turned into a type id, so the resource cannot be looked up or written.

```text
error[RE0103]: `.txt2` names no known resource type
```

Check the spelling of the extension against the file as the game ships it. A type id the table does not name is still read from an archive and kept as it is; only an extension with no id behind it is rejected.
