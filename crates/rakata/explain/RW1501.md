A changed path the tree does not hold.

A path of the `--changed` list names no file of the tree. Removed paths are marked `- ` and skipped; this one was marked as added or changed, or not marked at all, and the tree has no file of that name in any case.

```text
warning[RW1501]: 2 changed path(s) the tree does not hold, such as `Override/k_old.ncs`
```

The list may belong to another tree, or name the path from another root: paths are relative to the folder `--game` names, as `Override/appearance.2da`. The build goes on; the index reflects the files the tree holds.
