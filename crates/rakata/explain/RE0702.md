A 2DA header running past the end of the file.

After the signature a table carries its column names (each ending in a tab, the list ending in a NUL), a four-byte row count, one tab-ended label per row, two bytes of string offset per cell and a two-byte size field. The file ended before one of these sections did: a column list with no NUL, fewer labels than the row count promises, or an offset table cut short.

```text
error[RE0702]: the row labels at offset 61 run past the end of the 70-byte file
```

The file is truncated or was never a complete table. Nothing is read from it; obtain the whole file.
