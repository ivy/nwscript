A script that does not compile.

The authoring API compiles a mod's scripts through `nwscript`, as `nws compile` does, with `nwscript.nss` and the includes found among the mod's sources and then in the copy the install loads. The script has an error after the mode's lint levels apply; the message carries every diagnostic as `nws` prints it, each with its own code.

```text
error[RE1408]: k_oaj_bad.nss does not compile:
E0304

  × no function named `NoSuchRoutine`
   ╭─[k_oaj_bad.nss:1:15]
 1 │ void main() { NoSuchRoutine(); }
```

`nws explain CODE` explains each diagnostic. A decompiled BioWare script compiles with `--declarations bioware --compat bioware`, the authoring API's `Flags::BIOWARE`.
