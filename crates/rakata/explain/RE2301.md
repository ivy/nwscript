Not a room layout: no `beginlayout` line.

A room layout (`.lyt`) is text: a `#MAXLAYOUT ASCII` line and a `filedependancy` line naming the 3ds Max scene, then `beginlayout`, the sections, and `donelayout`. The file read has no line that is `beginlayout` alone, so it is another kind of file or a layout cut short before its body began.

```text
error[RE2301]: not a room layout: no `beginlayout` line
```

Check what the file is. An empty file is refused with this code, and so is a binary file whose bytes happen to be ASCII. The layout's format is `docs/formats/lyt.md` of the rakata repository.
