A 2DA cell whose string lies past the end of the file.

Each cell is an offset into the strings that follow the header, and its value runs from there to the next NUL. This cell's offset is past the end of the file, or no NUL follows it before the file ends. The header's size field is not involved: the reader takes the strings to run to the end of the file, as the game does, because editors ship tables with 0 in that field and TSLPatcher leaves a stale value behind when it appends, and the game reads both intact.

```text
error[RE0703]: the cell at row 2, column `aistate` points at offset 55 of the 56-byte strings and no NUL ends it
```

The file is truncated after its header, or an offset was written wrong. The table is not read as empty cells; obtain the whole file.
