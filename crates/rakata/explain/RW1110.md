A dialogue node whose `SoundExists` disagrees with its `Sound` and `VO_ResRef`.

BioWare's tool writes `SoundExists` on every node: nonzero when it found the line's audio, 0 when it did not. Its unrecorded lines (the player's replies among them) name a placeholder voice-over and carry 0. Two disagreements are reported: `SoundExists` 0 on a node whose `VO_ResRef` names a voice-over that is present, so the recording may go unplayed; and `SoundExists` nonzero on a node that names neither a `Sound` nor a `VO_ResRef`.

```text
warning[RW1110]: end_carth001.dlg voice:n_m1bncart01030_ has SoundExists 0, and its voice-over n_m1bncart01030_.wav is present (module end_m01ab)
```

Set `SoundExists` to 1 on a voiced line, as the authoring API does on every entry it adds with a voice-over.
