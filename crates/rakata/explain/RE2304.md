A room layout section whose rows disagree with its count.

Each section of a layout is a count line followed by exactly that many rows; the next keyword, or `donelayout`, ends the rows. In every vanilla layout each count is the number of rows that follow it. Here the count line declares one number and another follows, so either a row was added or removed without the count being changed, or a row was lost.

```text
error[RE2304]: line 4: `roomcount` declares 15 rows and 14 follow
```

Count the rows under the line named and set its count to match, or restore the row that was lost. Which of the two the engine believes is not established, so the reader refuses rather than guess.
