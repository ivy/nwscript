A byte outside ASCII in a layout or visibility file.

Layouts and visibility files are plain ASCII text: model names, keywords and numbers. Every vanilla file is ASCII. The byte named is above 0x7F, so the file is not one of these, or a name in it was written in another encoding.

```text
error[RE2306]: byte 0xe9 at offset 0x1f4 is not ASCII
```

Model names are resrefs, which the engine stores in ASCII; rename the model, or check that the file is a layout at all.
