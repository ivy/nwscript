A GFF whose file type is not `DLG `, read as a dialogue.

`rakata dialog` and the `rakata-dialog` model read conversations: GFF V3.2 files whose four-byte type is `DLG `. The file named holds another kind of GFF, such as a creature blueprint (`UTC `) or an area (`ARE `), or the name given was not `NAME.dlg`.

```text
error[RE1101]: m13aa.are is a `ARE` GFF, not a dialogue (`DLG `)
```

Name the dialogue itself: `rakata dialog show NAME.dlg --game DIR`, or the path of a `.dlg` file.
