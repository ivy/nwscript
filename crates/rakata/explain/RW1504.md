Files new to the tree that the changed list does not name.

An incremental build carries every file of its `--parent` over unread, except those the `--changed` list names. A file the parent does not hold is read whether or not the list names it, and this warning counts those the list left out: the list is incomplete, so a file it should have named as changed in place may have been carried over stale.

```text
warning[RW1504]: 3 file(s) the parent tree does not hold are not in the changed list, such as `Override/new.2da`; they were read
```

Check that the list belongs to this tree and that `--parent` is the tree it was computed against. A cold build (no `--parent`) and `rakata index digest --tree LABEL` over both databases show whether the incremental index is the same.
