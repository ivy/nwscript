A transcript or a set of mouth cues that does not read.

The voice helpers read two programs' JSON: a take's transcript (AWS Transcribe's, whose `results.audio_segments` carry `start_time` and `end_time`), and Rhubarb Lip Sync's output (`-f json`), whose `mouthCues` carry a `start` and a `value` among the shapes `A` to `H` and `X`, with `metadata.duration` the clip's length. The JSON does not parse, lacks one of those, or names a shape Rhubarb does not have.

```text
error[RE1412]: Rhubarb's cues does not read: cue 0 is not a start time and one of Rhubarb's shapes A to H or X
```

Run Rhubarb with `-f json --extendedShapes GHX`, and pass the file it wrote.
