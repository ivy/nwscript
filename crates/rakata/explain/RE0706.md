A 2DA column the table does not have.

Columns are named in the file and matched as written: the game looks them up case-sensitively, so `Label` is not `label`. No column has the name given. The row label is not a column; it is addressed through the row.

```text
error[RE0706]: the table has no column `Label`
```

Use the name as the table spells it; the table's columns are listed in file order.
