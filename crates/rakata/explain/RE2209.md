A TGA the writer cannot write as given.

The writer encodes the RGBA pixels back to the depth and order the header names, and writes the header from the image's fields and its layout. It refuses what the header cannot say: pixels whose length is not width × height × 4, an image ID longer than the 255 bytes its length byte counts, alpha bits above 15 (the descriptor gives them four bits), or bits in `descriptor_high` other than bits 6 and 7, which hold the descriptor's remaining bits in place.

```text
error[RE2209]: cannot write the TGA: 12 bytes of pixels for 2×2, which takes 16
```

Make the pixels match the size, or the size the pixels.
