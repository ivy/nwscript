A file a Lua script writes that could not be written.

`rakata.fs.write` creates the file's directory and writes the bytes whole; the operating system refused one of the two. The path is one of the script's inputs (otherwise the error is `RE1801`), so the cause is the file system: a directory where the file should be, permissions, or a full disk.

```text
error[RE1806]: cannot write `out/globalcat.2da`: Permission denied (os error 13)
```

Check that the path names a writable location. A write into the install goes through `Mod:write_override`, whose failures are `RE1409`.
