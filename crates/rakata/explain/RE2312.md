A visibility line that is neither `ROOM COUNT` nor an indented room.

A visibility file holds two kinds of line: a room line at the start of the line, a room's name and the count of rooms seen from it; and an indented line holding one room seen from the room line above. The line named has too many fields for either: a room line with more than a name and a count, or an indented line with more than one name.

```text
error[RE2312]: line 12 `m01aa_08a m01aa_08b` is neither `ROOM COUNT` nor an indented room
```

Put each room seen on a line of its own, indented, and keep only the name and the count on a room line. One vanilla room line has no count at all, which is read as a room seeing whatever indented lines follow it.
