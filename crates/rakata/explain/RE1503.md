A tree the index database does not hold.

A tree is named by the label it was built under (`rakata index build --tree LABEL`). `--parent LABEL` names the tree an incremental build carries rows over from, and `--tree LABEL` on `digest` and `coverage` names the tree to report on; either must already be in the database.

```text
error[RE1503]: the index holds no tree `ckpt:f107f61067d15feb`; it holds `vanilla`, `ckpt:6291e7503819c945`
```

Use one of the labels the message lists, or build the parent first: trees are indexed in chain order, each from the one before it. `rakata index query --db FILE "SELECT label FROM trees"` lists them.
