A 2DA row the table does not have.

A row is named by its label, a string the file carries beside each row, or by its position. No row carries the label given, or the position is past the last row. Labels are the row's position in most of BioWare's tables, but not in all: some carry names, some start elsewhere, and a label may repeat, in which case the first row carrying it is the one found.

```text
error[RE0705]: the table has no row with label `131`; it has 130 rows
```

Check the label against the table's own labels rather than assuming the position; a change file that adds a row names the label it will carry.
