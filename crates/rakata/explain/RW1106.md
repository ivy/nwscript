A condition reading a global `globalcat.2da` does not declare.

The engine keeps a global only when `globalcat.2da` declares its name and type; reading any other name answers 0 and setting it does nothing, so a condition gating on it never changes its answer. The condition's bytecode passes this name, as a string literal, to one of the engine's `GetGlobal*` routines.

```text
warning[RW1106]: dan14_juhani.dlg the start into E67 (voice:oaj_juh01) has the condition k_oaj_c_defeat, which reads the global OAJ_DONE, and globalcat.2da does not declare it
```

Declare the global (the authoring API's `globals::declare`) and write `globalcat.2da` before the dialogue.
