An input file could not be read.

The path named in the diagnostic does not exist, is not a file, or cannot be opened by the current user. Every input `rakata` reads is named on the command line or found inside the install `--game` names, so the path in the message is the one to check.

```text
error[RE0001]: cannot read `missing.utc`: No such file or directory
```

Check the spelling and the working directory, or pass the file's full path. When the file is inside the install, check that `--game` names the folder holding `chitin.key`.
