A quest `global.jrl` has no category for, or a tree without `global.jrl`.

`rakata quest TAG` reads the journal from the tree's `global.jrl` (an `Override/` copy first, else the one in the game's archives) and looks for the category whose `Tag` is TAG, without regard to case. The journal has no such category, or the tree holds no `global.jrl`.

```text
error[RE2102]: data/_newbif.bif!global.jrl has no category tagged `kor37_ajunta`
```

A quest's tag is the category's `Tag`, which dialogue nodes name in their `Quest` field and scripts pass to `AddJournalQuestEntry`. `rakata index query "SELECT value FROM gff_fields WHERE label = 'Tag' AND path LIKE 'Categories[%'"` lists the tags the index holds.
