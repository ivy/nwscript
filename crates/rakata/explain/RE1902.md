A paths file or known list for `rakata lint` that cannot be read or does not parse.

`--paths FILE` names the files to check, one per line, relative to the tree, optionally marked as a modshop checkpoint's `changed.txt` marks them (`+ `, `~ `, `- `; removed paths are skipped). `--known FILE` is a known list: a TOML table per code, each path a key whose value is the list of its sites.

```toml
[RW1901]
"modules/danm13.rim!module.ifo" = ["Mod_OnPlrDying", "Mod_OnSpawnBtnDn"]
```

```text
error[RE1902]: cannot read the known list conformance/tree-known.toml: expected `=` at line 4
```

Check the path, or the file's syntax. `rakata lint --write-known FILE` writes a tree's findings in this form.
