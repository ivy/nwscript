A 2DA row label that matches more than one row, or a new row's label the table already carries.

A row is addressed by its label: the `label` column where the table has one (as `appearance.2da` does, whose row labels are their indices), and the row label otherwise. A label naming several rows does not say which to copy; a new row given a label another row has would make that label name two.

```text
error[RE1405]: the table already has a row labelled `Juhani_Clones_Hidden` (row 641)
```

Name the source row by index, or give the new row a label of its own.
