An index query SQLite rejects.

`rakata index query --db FILE SQL` runs one SQL statement against the database, opened read-only. SQLite rejected the statement: it does not parse, names a table or column the schema does not have, or would change the database.

```text
error[RE1504]: the query `SELECT * FROM call` failed: no such table: call
error[RE1504]: the query `DELETE FROM refs` failed: attempt to write a readonly database
```

`docs/index.md` lists every table and column. Full-text search uses the `search` table with FTS5's `MATCH` (`SELECT kind, site, body FROM search WHERE search MATCH 'rakghoul*'`); call arguments are JSON, read with `json_extract(args, '$[0]')`.
