A node key that matches more than one node of the dialogue.

A stable key must name exactly one node, or an edit made through it could land on the wrong line. Text keys are the usual cause: a short line such as an empty reply occurs many times in one conversation. The message names every node the key matches.

```text
error[RE1103]: text:"Hello." matches 2 nodes of fixture.dlg: E0, E1
```

Use a key that is unique: the node's voice resref or its strref, shown for each node by `rakata dialog show`. An index (`E3`) is unique but moves when nodes are inserted before it, so it is marked fragile.
