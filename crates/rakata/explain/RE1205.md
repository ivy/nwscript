A global the install's `globalcat.2da` does not declare was set without `--declare`.

The game's scripts read and write only the globals `globalcat.2da` declares; a name the table lacks is one no script reads, so `rakata save set` refuses it. The table is the one the install named by `--game` loads (`Override/` first, then the BIFs). Names compare without regard to case.

```text
error[RE1205]: the install's globalcat.2da does not declare the global `OAJ_DONEE`, so the game's scripts would not read it
```

Check the spelling with `rakata 2da show globalcat.2da --game DIR --column name`, or name the install the save was made with. To write the name into the save anyway, pass `--declare` (`docs/saves.md` says what it does to the save); the install still has to declare it before a script reads it.
