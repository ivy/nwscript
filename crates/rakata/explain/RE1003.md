A corpus manifest did not read or parse.

`rakata corpus verify` checks a corpus against two TOML files: the manifest (`conformance/k1.toml` by default), which names every script `chitin.key` lists with the sha256 of its NSS and NCS, and the modules file beside it (`k1-modules.toml`), which names every capsule's NCS. One of the two is missing, is not TOML, or has a key in a shape the reader does not take.

```text
error[RE1003]: conformance/k1-modules.toml: No such file or directory (os error 2)
```

Pass `--manifest FILE` naming the manifest; its modules file is found beside it by name. Both are written by `rakata corpus extract --manifest FILE`, and only names and hashes go in them.
