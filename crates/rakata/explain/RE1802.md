A module a Lua script requires that is not in the script's directory.

`require` in a `rakata lua` script loads only modules beside the script: `require "lib.scenes"` reads `lib/scenes.lua` below the script's directory, and `require "rakata"` returns the façade. A module name is dotted words of letters, digits, `_` and `-`; one with `..`, a slash or an empty part is refused, and there is no search path, no C module and no `package` library.

```text
error[RE1802]: no module `scenes` in the script's directory: ./mods/scenes.lua: No such file or directory
```

Move the module beside the script, or name it by its path below the script's directory with dots.
