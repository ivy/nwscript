A voice-over for `streamwaves/` that is not a RIFF WAVE file.

The game plays a dialogue's voice-over from `streamwaves/` as a WAV file: every one KotOR 1 ships is an MP3 stream behind a 58-byte RIFF header that declares 8-bit PCM. Bytes that do not begin `RIFF`, then four bytes, then `WAVE`, are not one, and the game would not play them.

```text
error[RE1413]: oaj_juh02.wav does not begin with a RIFF WAVE header, which the game's voice files carry
```

Wrap an MP3 with the voice helpers' `streamwave`, which puts the game's header in front of it.
