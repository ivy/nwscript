Not an archive of the kind asked for.

Every archive begins with eight bytes naming its kind and version: `KEY V1  `, `BIFFV1  `, `RIM V1.0`, or one of `ERF V1.0`, `MOD V1.0`, `SAV V1.0` and `HAK V1.0`. The file read begins with something else, so it is a different kind of archive, a different version, or not an archive at all.

```text
error[RE0201]: not a `RIM V1.0` archive: the file begins `MOD V1.0`
```

Open the file with the reader for the kind it names; a `.mod` is an ERF, a `.rim` a RIM. When the first eight bytes are not a signature at all the file is not an archive, whatever its extension.
