A layout or visibility value the text form cannot hold.

The writer spells every number as the vanilla files do and every name as one token. A coordinate or quaternion component that is not finite (NaN or an infinity) has no such spelling, and a name that is empty, holds whitespace or holds a byte outside printable ASCII would not read back as the same name. The writer refuses rather than write a file that reads differently.

```text
error[RE2307]: cannot write `M01aa_08c`: the value is not finite
```

Find where the value was computed or the name was set, and give it a finite number or a single-token name.
