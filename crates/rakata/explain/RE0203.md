An archive member lying beyond the end of the file.

The archive's table gives a member an offset and length that reach past the end of the file. The header and tables themselves read, so the file is complete up to its tables and short after them, or the table entry is wrong.

```text
error[RE0203]: member k_pdan_juhani31.ncs at offset 1048576 for 2048 bytes lies beyond the end of the 1049000-byte file
```

For a BIF, whose members have no names, the message gives the member's position in the table instead. Compare the file's size with its source; a copy that stopped early is the usual cause.
