The install has no `nwscript.nss` to read the engine's declarations from.

Decompiling needs the engine's routine table: `nwscript.nss`, which every KotOR install ships in `scripts.bif` through `chitin.key`, and which a mod may also place under `Override/`. `rakata corpus decompile` reads the copy the engine would load and finds none in either place, so no ACTION instruction can be named and no recovered source can be checked by recompiling.

```text
error[RE1002]: `games/swkotor` has no nwscript.nss to read the engine's declarations from
```

Point `--game` at a complete install, the folder holding `chitin.key` with its `data/` BIFs beside it. `rakata which nwscript.nss --game DIR` shows where the install keeps it, or that it does not.
