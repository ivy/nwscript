The save holds no state for the module asked for.

A save keeps one nested archive per module the player has visited, `SAVEGAME.sav/STEM.sav`, named by the module's stem (`danm14ac`), not by its area (`m14ac`) or its name in the game (`Dantooine - Grove`). A module the player has not entered has no state in the save. Case does not matter.

```text
error[RE1202]: the save holds no state for module `danm15`; it holds danm13, danm14aa, danm14ab, danm14ac
```

Pick a module from the list the message gives, or run `rakata save show DIR` without `--module` to see them.
