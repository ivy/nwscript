A field path that does not parse.

A field path is labels separated by `.`, each optionally followed by `[n]` to pick the n-th struct of a list: `EntryList[3].RepliesList[0].Index`, `Map.MapResX`, `Tag`. The empty path names the root struct. This text is not one.

```text
error[RE0606]: cannot parse the path `EntryList[3.Index`: a `[` without its `]`
error[RE0606]: cannot parse the path `EntryList[x]`: an index that is not a number
```

A label may hold spaces (`Creature List[0].TemplateResRef`) but not `.`, `[` or `]`; a field whose label holds one of those cannot be named by a path.
