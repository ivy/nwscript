A directory that is not a saved game: it holds no `SAVEGAME.sav`.

A KotOR save is a directory under the game's `Saves/` folder, named `NNNNNN - GameN`, holding `SAVEGAME.sav` (the archive of the party members and of each visited module's state) and, beside it, `GLOBALVARS.res`, `PARTYTABLE.res`, `savenfo.res` and a screenshot. `rakata save show DIR` takes that directory, not the `Saves/` folder above it and not the archive inside it. Names compare without regard to case.

```text
error[RE1201]: Saves is not a saved game: it holds no SAVEGAME.sav
```

Pass one save's directory: `rakata save show "Saves/000023 - Game22"`. `docs/formats/save.md` describes the layout.
