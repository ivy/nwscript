A 2DA string the layout cannot hold.

In the file a cell ends at a NUL, and a column name or row label at a tab (the column list at a NUL), so none may contain its own terminator. Every byte is one character of the game's single-byte code page, Windows-1252, so a character outside it has no byte to be written as.

```text
error[RE0708]: the cell at row 3, column `name` cannot be written: `中` (U+4E2D) is outside the game's code page
```

Localized text belongs in `dialog.tlk`, with the table carrying its string reference as a decimal number; a cell may hold any other character of the page. Remove the terminator from the name or label.
