Two voice lines with one resref.

Each voice line becomes its own files, `streamwaves/RESREF.wav` and `Override/RESREF.lip`, named by the resref the dialogue's node plays. Two lines name the same one (the game compares names without regard to case), so one would overwrite the other.

```text
error[RE1411]: two voice lines are named OAJ_JUH01; each line is its own file
```

Give each line its own resref, at most sixteen characters.
