A decompiled script some of whose functions did not verify.

`rakata decompile` recompiles the recovered source and compares each function's bytes with the original. A function that compiles to other bytes is unverified: its source says what the decompiler believes, which may not be what the script does.

```text
warning[RW2001]: k_odd.ncs: 3 of 4 functions verified
```

Read an unverified function against `nws disasm` of the script before relying on it.
