A value of the wrong kind passed to a function of the Lua binding.

A binding function checked an argument and refused it: an option table with a key the function does not take, a game profile other than `k1` or `k2`, a node kind other than `entry` or `reply`, a row that is neither an index from 0 nor a label, a number that does not fit the GFF field it is set into, or a new GFF field given a plain value, whose type the binding cannot know.

```text
error[RE1805]: Install.open takes no option `profle`; its options are profile
```

`rakata lua --reference` documents every function's arguments. A new GFF field takes a typed value, as `rakata.gff.byte(5)`.
