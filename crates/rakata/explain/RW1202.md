A global was written that the install's `globalcat.2da` does not declare.

With `--declare`, `rakata save set` writes a global the install does not declare: when the save lacks the name, it is appended to the save's catalogue of its type (`CatBoolean`, `CatNumber`, `CatString` or `CatLocation` in `GLOBALVARS.res`) and its value written beside it. The save then carries it, but the game's scripts read only the globals `globalcat.2da` declares, so none reads this one until the install declares it too.

```text
warning[RW1202]: `OAJ_TEST` is written to the save, but the install's globalcat.2da does not declare it, so no script reads it
```

Add the row to the install's `globalcat.2da` (the mod that uses the global does this) before loading the save.
