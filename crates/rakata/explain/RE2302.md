A room layout line in no form the layout takes where it stands.

Before `beginlayout` a layout takes only lines beginning `#` and one `filedependancy NAME`. Inside it, each section is a count line (`roomcount`, `trackcount`, `obstaclecount` or `doorhookcount`, then a number) followed by that many rows: `MODEL X Y Z` for a room, track piece or obstacle, and `ROOM NAME 0 X Y Z W X Y Z` for a door hook. `donelayout` ends the layout. The line named is none of what may stand there: an unknown keyword, a count line without its number, or a row with too few or too many fields.

```text
error[RE2302]: line 5 `M01aa_08c 39.4685 130.475` is not a row `MODEL X Y Z`
```

Compare the line with its neighbours. A row missing a coordinate was usually damaged by a hand edit; a keyword the list above does not name is not one the vanilla files use.
