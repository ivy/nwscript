A resource type id wider than sixteen bits.

RIM and BIF tables store a resource's type in a 32-bit field, but a type is a 16-bit id (the KEY and ERF tables store it as one), and every entry BioWare shipped has zero in the upper half. An entry with the upper half set is not a type this toolset can name.

```text
error[RE0204]: entry 12 has resource type id 65538, wider than the sixteen bits a type holds
```

The file was written by a tool that put something other than a type in the field, or is corrupt. The toolset refuses rather than guess at the lower half.
