`Override/` holds two or more files whose names differ only in case.

The engine compares resource names without regard to case, and on Windows a file system does the same, so one name is one file. The game runs under Wine on case-sensitive file systems, where an installer that writes `PLC_Invis.utp` beside an existing `plc_invis.utp` leaves two files under one name. Which of them the engine opens is not established, so the resolution names both, marks the first ambiguous, and does not guess.

```text
warning[RW0401]: Override holds 2 files that differ only in case: Override/plc_invis.utp, Override/PLC_Invis.utp
```

Remove all but one. The newest is usually the one the last installer meant to write; `rakata which --duplicates` lists every such group in an install.
