`Override/` already holds a copy of a resource the mod replaces.

`Override/` outranks the module's capsules, so a copy there is another mod's replacement of the same resource (or this mod's own, written earlier in the run). Writing over it would drop that mod's change.

```text
error[RE1402]: Override already holds k_pdan_juhani31.ncs (Override/k_pdan_juhani31.ncs), from another mod; replacing it would drop that mod's change
```

Install the mod onto a tree without that file, or merge the two changes into one replacement.
