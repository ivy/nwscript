A Lua script that opens the install when no --game was named.

`rakata.Install.open` and `rakata.dialog.Session.open` open the install `rakata lua --game DIR` names; there is no default install, for the same reason every other `rakata` command has none: a script's inputs are named on its command line.

```text
error[RE1803]: the script opened the install, and no install was named: pass --game DIR, the folder holding chitin.key
```

Run the script with `--game DIR`, the folder holding `chitin.key`.
