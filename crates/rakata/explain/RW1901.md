A reference that resolves to nothing in the install.

`rakata lint` checks every resref a resource names against what the install holds: a GFF's `CResRef` field (a creature's scripts and conversation, a placeable's inventory, an area's models), a cell of a 2DA column that holds resrefs (`appearance.2da`'s `modela`, `spells.2da`'s `impactscript`), and a string literal a script passes to an engine routine's resref parameter (`ExecuteScript`'s `sScript`, `CreateObject`'s `sTemplate`). The type each site names is measured from the vanilla game (`crates/rakata/src/lint/sites.toml`); a script parameter's type follows the words of its name in `nwscript.nss`, and a template's the call's `OBJECT_TYPE_*`. A field the table does not type resolves as any type.

```text
warning[RW1901]: `modules/danm13.rim!m13aa.git` Creature List[2].TemplateResRef names `dan13_droid`, which no layer of the install holds
```

A member of a module's capsule resolves against the global layers and that module's capsules; a file anywhere else (`Override/`, a BIF, `patch.erf`) against every layer of every module. The global layers are `Override/`, `patch.erf`, the BIFs, the texture packs, `rims/`, `lips/`, `streamwaves/`, `streammusic/`, `streamsounds/` and `movies/`.

The engine does without what it cannot find (a missing script does not run, a missing model is not drawn), so the game goes on and what was meant does not happen. Add the resource, or correct the name. The vanilla game's own findings are in `conformance/tree-known.toml`; `--known` accepts a list of them.
