Pixels the PNG encoder cannot write as given.

`Rgba::to_png` writes 8-bit RGBA, so it needs `width × height × 4` bytes of pixels and a size the PNG format takes (neither side zero). The image given has another number of bytes, or a zero side.

```text
error[RE2212]: cannot write the PNG: 5 bytes of pixels for 3×2 RGBA, which takes 24
```

Give the image as many bytes as its size takes, four per pixel.
