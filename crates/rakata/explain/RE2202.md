A TPC encoding that names no pixel format.

The byte at offset 12 of a TPC, read with the data-size field at offset 0, names the pixel format: 1 with a zero data size is greyscale, 2 is RGB, 4 is RGBA; 2 with a non-zero data size is DXT1, 4 is DXT5. These five are every format the KotOR 1 files use. The file read has another combination.

```text
error[RE2202]: TPC encoding 1 with a non-zero data-size field names no pixel format
```

The file is a format this crate has not measured (another game's TPC, or a tool's extension), or its header is damaged. Converting the texture to one of the five formats lets it be read.
