A script several modules hold, with no module named, and that no global layer holds.

Without `--module`, `rakata decompile` looks for `NAME.ncs` in `Override/`, `patch.erf` and the BIFs, then in every module's capsules. When exactly one module holds it, that module is used. When several do, the copies may differ, and which one is meant is the user's choice.

```text
error[RE2002]: k_ai_master.ncs is in no global layer and in 2 modules: danm13, danm14aa; name one with --module
```

Pass `--module STEM` with one of the modules named.
