A room layout with no `donelayout` line.

A layout ends with a line that is `donelayout` alone, after its last section. The file read reaches its end without one: it was cut short, or the line is misspelled.

```text
error[RE2305]: the layout has no `donelayout` line
```

Re-extract the file from its archive if it was cut short; otherwise add the line after the last door hook.
