A GFF section or field lying beyond the end of the file.

The header names the offset and size of six sections (structs, fields, labels, field data, field indices, list indices), and a field's data in turn names its own length. One of these runs past the end of the bytes: the file was cut short, or a writer's header disagrees with what it wrote after it.

```text
error[RE0602]: the field data block at offset 3124 for 9795 bytes lies beyond the end of the 4096-byte file
error[RE0602]: the data of field 21 (Text) at offset 400 for 1200 bytes lies beyond the end of the 344-byte file
```

Compare the file's size with its source's; a copy that stopped early is the usual cause. When the file is one a tool wrote, the tool is at fault and the file will not load in the game either.
