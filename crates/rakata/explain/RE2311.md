A visibility file's indented room before any room line.

A visibility file (`.vis`) is a list of room lines, each `ROOM COUNT` at the start of a line, and under each the rooms seen from it, one to a line, indented. An indented line belongs to the room line above it. The line named is indented and no room line comes before it, so it belongs to nothing.

```text
error[RE2311]: line 1: indented room `m01aa_08a` comes before any room line
```

The file has lost its first room line, or its first line was indented by mistake. Every vanilla file begins with a room line.
