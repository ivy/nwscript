The directory named as the game install holds no `chitin.key`.

Every command that reads the game takes `--game DIR`, the folder the game is installed in: the one holding `chitin.key`, `dialog.tlk`, `Override/` and `modules/`. The folder is found case-insensitively, as the engine finds it under Wine, but the file must exist.

```text
error[RE0401]: `games/swkotor/Override` is not a game install: it holds no chitin.key
```

Name the install's root, not a folder inside it. A Steam install of KotOR 1 is `steamapps/common/swkotor`; a modded build made by a tool keeps the same layout.
