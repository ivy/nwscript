A walkmesh truncated before its header or one of its arrays ends.

A walkmesh is a 136-byte header, then nine arrays the header places by count and offset: vertices, faces, materials, normals, plane distances, the AABB tree, adjacency, perimeter edges and perimeters. The file read is shorter than the header, or an array the header describes runs past the end of the file.

```text
error[RE2502]: the walkmesh's perimeter array needs 26404 bytes and the file has 26403
```

The file was cut short in copying or extraction, or a count or offset in its header is damaged. Re-extract it from its archive (`data/models.bif` for the game's own).
