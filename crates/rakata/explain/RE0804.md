A talk table entry with text but without the text-present flag.

Each entry carries flags that say what the engine should read: `0x1` for the text, `0x2` for the sound resref, `0x4` for the sound length. An entry whose text flag is clear is written with no text at all, offset 0 and size 0, as BioWare writes the lines it left blank; so an entry that has text while its flag is clear would lose that text on write, and the engine would never show it.

```text
error[RE0804]: strref 12 has text but its flags do not set TEXT_PRESENT (0x1)
```

Set the flag on the entry, or clear its text. An entry built with `Entry::new` carries BioWare's flags, all three bits, and never reaches this error.
