A model's or a layout's reference that resolves to nothing in the install.

`rakata lint` checks what the binary models and the room layouts name, as the index records it (`rakata_mdl::facts`, `rakata_lyt::facts`): a mesh's texture (`NODE.texture`) and lightmap (`NODE.lightmap`) and a light's flare textures (`NODE.flare[N]`), each a texture, which a `.tpc`, `.tga` or `.dds` of the name satisfies; and a model's supermodel (`supermodel`), a reference node's model (`NODE.model`), and a layout's rooms, swoop track pieces, obstacles and door hooks' rooms (`room[N]`, `track[N]`, `obstacle[N]`, `doorhook[N].room`), each a model. `NULL`, `****` and empty names are not references.

warning[RW1906]: `data/models.bif!m01aa_04a.mdl` Object5044.lightmap names `m01aa_04a_a0002t` as a tpc, and no layer of the install holds one

The name is matched as written: whether the engine completes a texture name it cannot find, as it completes `appearance.2da`'s texture prefixes, is not established, and how it draws a mesh whose texture is missing is not measured here. Add the resource, or correct the name.
