A walkmesh index naming no element of the array it points into.

A walkmesh's arrays refer to one another: a face names three vertices, an adjacency entry or perimeter edge names an edge as `face * 3 + edge`, a perimeter names the end of its run of edges, and an AABB node names a face or two child nodes. Where an entry may name nothing it holds -1. The entry read names an element past the end of its array, or holds a negative value other than -1; or the adjacency array has more rows than there are faces.

```text
error[RE2504]: the walkmesh's face vertex 12 is 140, and the array it names holds 114
```

The file is damaged, or a tool wrote its arrays in another order than the header's offsets say. Re-extract or regenerate the walkmesh.
