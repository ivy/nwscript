A 2DA a shown value names that the install lacks or that does not read.

`rakata show` names an item's properties and base item through the 2DAs the engine uses (`itempropdef`, its subtype, cost and parameter tables, `baseitems`), looked up as the engine loads them. When one is missing or does not read, the values it would name are shown by row number.

```text
warning[RW2002]: no layer of the install holds iprp_damagecost.2da, so its rows are shown by number
```

A modded install that removed or broke the table has a fault of its own; `rakata which NAME.2da --game DIR` shows which copy wins.
