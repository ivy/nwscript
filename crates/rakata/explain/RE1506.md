A `refs` symbol that cannot be of the kind asked for.

`rakata refs THING --kind KIND` looks for one kind of symbol, and THING must be a value of it: a strref is a decimal number from 0 to 4294967295, a resref is one to sixteen characters (an extension after it, as in `k_trans_abort.utp`, is dropped), and a tag or a global is any text that is not empty.

```text
error[RE1506]: `k_transabort` cannot be a strref: a strref is a decimal number
```

Give the kind THING is, or `--kind auto` (the default), which tries every kind THING can be and says which matched.
