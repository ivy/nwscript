A walkmesh count, offset or index too large for the field it is written to.

The layout stores counts and offsets as unsigned 32-bit integers, and the indices that may name nothing (an AABB node's face and children, an adjacent edge, a perimeter edge's transition) as signed 32-bit integers where -1 is none. An edge is stored as `face * 3 + edge`, with `edge` 0, 1 or 2. A walkmesh built in memory holds a value one of these fields cannot carry, so it cannot be written.

```text
error[RE2506]: the walkmesh's perimeter edge's transition is 3000000000, and the field it is written to holds at most 2147483647
```

No vanilla walkmesh comes near these limits; a value this large comes from a computation that went wrong upstream. Check the code that built the walkmesh.
