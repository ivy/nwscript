A write the read-back did not find: the target holds other bytes than the installer wrote.

After every operation `rakata install` reads the file or capsule member it wrote back from the disk and hashes it. When the hash differs from that of the bytes written, or the member is not there at all, the operation did not land, and the installer says so rather than reporting success. The causes are a writer that put back other bytes (an archive writer that kept the old copy of a member it was told to replace), another process writing the same file between the write and the read-back, or a file system that does not keep what it is given.

```text
error[RE0305]: [InstallList] line 14, Replace0 x.ncs into modules\danm13.mod: wrote 5f0c… to modules/danm13.mod:x.ncs, and the read-back found 91ab…
```

Both hashes are in the report. Find what else writes the target, then run the install again onto a fresh copy of the game.
