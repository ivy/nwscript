A dialogue write refused: a node or link it adds or changes, or an end script it sets, refers to something the install lacks.

Before writing a dialogue, the authoring API runs the reference checks the lints apply: each node's script, each link's condition and the dialogue's `EndConversation` and `EndConverAbort` resolve to bytecode (RW1102), each voiced node's voice-over exists (RW1104), each strref lies inside the talk table (RW1105), and each global a condition reads is declared (RW1106). A finding the copy the game loads already has is the game's or another mod's, and is reported as a warning; one the edit introduced refuses the write, and the file on disk is unchanged. The message names each finding with its code, the node's stable key (for an end script, the field) and what is missing.

```text
error[RE1407]: banter.dlg not written: banter.dlg voice:oaj_beat01 names the script k_oaj_missing, which no layer of the install holds [RW1102]
```

Write what the dialogue refers to first: compile and write its scripts, write its voice-overs, declare its globals; then write the dialogue.
