An include library that does not compile, so its functions are not folded.

To fold includes, `rakata corpus decompile` compiles every NSS of the install that has no entry point through a driver script that includes it and calls each of its functions, then indexes the bytes of each function. A library the project's compiler rejects, or whose driver cannot be formed, is left out: scripts that used it keep those functions in their own recovered source, under `sub_OFFSET` names, and nothing else changes.

```text
warning[RW1002]: k_inc_broken does not compile as an include library, so its functions are not folded: error[E0303]: `GN_Undefined` is not declared
```

`nws check --game k1 -I DIR LIB.nss` shows the library's own diagnostics. A library that only compiles after another include, or that needs a prototype the including script supplies, is a known shape of BioWare's sources and stays unfolded.
