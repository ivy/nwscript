A TXI line that would not read back as written.

A TXI is lines of a keyword and a value, and the numeric rows after a keyword; the reader trims each line, splits the keyword at the first whitespace, reads a line that begins with a digit, a sign or a point as a row, and reads bytes as Latin-1. The writer refuses an instruction that would read back as something else: a keyword that is empty, holds whitespace, or begins like a row; a row that does not; a value or row with a line break, a NUL, or whitespace at either end; or a character outside Latin-1, which has no byte.

```text
error[RE2208]: cannot write the TXI line `two words`: whitespace or NUL in a keyword
```

Correct the keyword, value or row named, so that the line is one keyword and its value, or a numeric row.
