A lip-sync keyframe with a shape above 15.

Each keyframe's fifth byte selects one of the sixteen mouth shapes the engine knows, numbered 0 (rest, the mouth closed) to 15. A byte above 15 names no shape; what the engine would do with one is not established, and no file the game ships carries one.

```text
error[RE0903]: keyframe 7 has shape 16; the sixteen shapes are 0 to 15
```

The file was written by a tool with a wider shape table, or the keyframes are misaligned (a header of the wrong length, a keyframe stride other than 5) so that a time's byte is being read as a shape. Check the writer; this crate never emits a shape above 15.
