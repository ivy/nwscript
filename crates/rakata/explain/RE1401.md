A module copy of a resource the mod replaces that is not the copy the mod was written against.

A mod that replaces a game resource outright (a script, say) guards it by the SHA-256 of the game's copy: every copy in the module's capsules (`STEM.mod`, `STEM.rim`, `STEM_s.rim`) must have that hash. One does not, so another mod or a patch changed it, and replacing it would drop that change without a word. The message names the capsule.

```text
error[RE1401]: danm14ac_s.rim's k_pdan_juhani31.ncs is not the copy the mod replaces (SHA-256 1f2e..., expected f684...); replacing it would drop what that copy does
```

Find what changed it with `rakata which NAME --module STEM --game DIR`, then merge its change into the mod's replacement and guard the new hash.
