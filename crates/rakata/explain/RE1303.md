A `gff set` naming a field that does not exist, without a type to create it.

`PATH=VALUE` reads the value as the type of the field at `PATH`. No field is there, so there is no type to read it as, and `rakata gff set` does not guess one: a field of the wrong type is a value the game reads as zero or not at all.

```text
error[RE1303]: `Plot` names no field, and without a type none is created
  = help: to create it, name its type: `Plot=TYPE:1`
```

Check the label's spelling and case against `rakata gff show FILE`; labels are case-sensitive. To create the field in the struct `PATH` ends in, name its type, as `Plot=byte:1`. The struct itself must exist.
