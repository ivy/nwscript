A talk table too large for its 32-bit fields.

The header counts entries in a 32-bit word and locates the string data with another; each entry locates its text with a 32-bit offset and size. A table with more entries, or more text, than those fields can address cannot be written.

```text
error[RE0805]: string data of 4294967300 exceeds the 32-bit field that holds it
```

The game's own table is five megabytes; a table this size is a defect in whatever built it. Check the loop that appended to it.
