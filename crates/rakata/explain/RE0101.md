A resource name longer than the sixteen bytes a resref holds.

The engine names every resource by a resref: at most sixteen bytes, compared without regard to case. Archives store the name in a fixed sixteen-byte field, so a longer name cannot be written, and the engine would never find it.

```text
error[RE0101]: resource name `k_my_very_long_script_name` is 26 bytes; a resref holds at most 16
```

Shorten the name to sixteen bytes or fewer, and change every reference to it: scripts that name it, dialogue nodes, blueprints and `changes.ini` entries. Mind that the limit is bytes, so a name with characters outside ASCII reaches it sooner than its character count suggests.
