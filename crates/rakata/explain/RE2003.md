A script the decompiler could not recover.

The copy the engine loads was found, but its bytecode did not decode, or the include libraries the decompiler folds with could not be built from the install (no `nwscript.nss`, RE1002). The message carries the reason.

```text
error[RE2003]: k_bad.ncs could not be decompiled: the install holds no nwscript.nss
```

`nws disasm` shows the bytecode as it is. A script the engine runs and the decoder refuses is a defect in the decoder.
