Override files whose names differ only in case.

The game runs under Wine on a case-sensitive file system, where `Foo.utc` and `foo.utc` are two files; the game asks for the name in one case, and which of the two it opens is not established. A patcher that writes the name its ini spells beside an existing file of another spelling leaves both.

```text
warning[RW1903]: `Override/N_XorH.tpc` differs only in case from `n_xorh.tpc`
```

Each file of a group is reported. Keep one: the one the latest mod wrote is the one it meant (modshop's `collapse_case` keeps the newest). `rakata which NAME.EXT` shows a group, and `rakata which --duplicates` every group.
