A structure of the MDL lies past the end of its model data.

An MDL's model data is a header, a name array and a tree of nodes, each reached by an offset from the start of the model data, and each node's arrays (children, faces, the triangle list, the positions) are reached the same way. One of them, the one named in the message, needs bytes past the end of the data: the file was cut short, or an offset in it is damaged.

```text
error[RE2402]: the MDL's face array at model offset 81244 needs 6400 bytes and the model data has 80000
```

Model offsets count from the end of the 12-byte file header, so add 12 to find the byte in the file. Re-extract the model from its archive (`data/models.bif` for most of the game's own).
