A `namespaces.ini` without options.

An installer that offers choices lists them in `namespaces.ini`: a `[Namespaces]` section with `Namespace1=`, `Namespace2=`, ... naming the sections that describe each option. A file without a `[Namespaces]` section, or with one that lists nothing, offers nothing to choose, and `rakata install` cannot pick a changes file.

```text
error[RE0304]: namespaces.ini has no [Namespaces] section
```

Add the `[Namespaces]` list, or remove the file so the installer reads `changes.ini` directly.
