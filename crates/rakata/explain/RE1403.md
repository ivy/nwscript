The module holds no copy of a resource the mod replaces.

The guard compares every copy in the module's capsules with the hash the mod was written against. There is none, so the mod names the wrong module, the wrong resource, or an install that differs from the one it was written for; or the mod named no module at all.

```text
error[RE1403]: the module danm14ac holds no k_pdan_juhani99.ncs to replace
```

`rakata which NAME --module STEM --game DIR` lists every copy the install holds.
