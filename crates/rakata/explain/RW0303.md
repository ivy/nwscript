A section or key written twice.

TSLPatcher reads its files through the Windows INI functions, which answer with the first section of a name and the first key of a name within it; the second is never read. `rakata` does the same and reports the repeat, because a repeat is usually a copy-and-paste that was meant to be a new entry.

```text
warning[RW0303]: section `[gff_man_yortal_InventoryRes_0]` is written again; the first is read
warning[RW0303]: `File5` is written again in [GFFList]; the first is read
```

Rename or remove the repeat. When the two differ, the first is what installs.
