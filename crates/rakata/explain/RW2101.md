A journal entry nothing in the index writes.

`rakata quest` lists, for each entry of a journal category, what writes it: a dialogue node whose `Quest` names the category and whose `QuestEntry` is the entry's `ID`, and a script calling `AddJournalQuestEntry` with the category's tag and the entry's id as literals, directly or through a function of the script's own. No node and no call names this entry, so the player never sees it unless something the index cannot read writes it.

```text
warning[RW2101]: entry 30 of the quest `tat18ac_dragonhunt` is written by no dialogue node and no script call the index holds
```

A note follows when some `AddJournalQuestEntry` call for the quest computes its entry (from a variable or an expression the index does not follow): such a call may be the writer. A save game or a mod may also write the entry. An entry no one writes is often a cut path; it is a finding to read, not a defect to fix blindly.
