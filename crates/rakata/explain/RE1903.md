An index database holding no tree built from the install.

`rakata lint --db FILE` reads the contents of the install from an index instead of walking it: the tree whose root, as `rakata index build --game` recorded it, is the `--game` folder, symbolic links resolved. The index holds no such tree.

```text
error[RE1903]: the index `index.sqlite` holds no tree built from `games/swkotor`: build one with `rakata index build --game games/swkotor --tree LABEL --db index.sqlite`
```

Build the tree into the index, or name the folder it was built from. An index answers for the tree as it was when built; after a change, build it again (`--parent` and `--changed` make that quick).
