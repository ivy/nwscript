A name `rakata decompile` takes that is not a script's `NAME.ncs`.

`rakata decompile` reads the bytecode the engine loads, so the name is a script's resref with `.ncs` or no extension. A source file (`.nss`) is not decompiled; another extension names another kind of resource.

```text
error[RE2001]: `k35_uth_hassword.nss` is not a script's name, NAME.ncs
```

Name the compiled script: `rakata decompile k35_uth_hassword.ncs --module korr_m35aa --game DIR`.
