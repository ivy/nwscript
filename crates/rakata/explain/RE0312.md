A file `[Settings]` requires that is not installed; nothing is installed.

`Required=FILE` names a file that must be in `Override` before the mod installs, usually one a mod this one builds on puts there. TSLPatcher stops with `RequiredMsg` as its message, and so does `rakata install`: no operation runs.

```text
error[RE0312]: override\k_fp_barrier1.ncs is not there: "K2 Force Powers for K1" must be installed first
```

Install the mod the message names first.
