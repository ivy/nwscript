A BIF with fixed resources.

A BIF header counts, besides its variable resources, a number of fixed resources with a table of their own. Every BIF BioWare shipped with KotOR 1 and 2 counts zero, so the layout of that table is unmeasured and this toolset does not read it.

```text
error[RE0208]: the BIF counts 3 fixed resources, a table this crate does not read
```

The file is from another game or another tool. If it is one this toolset should read, the fixed-resource table needs measuring on real files first.
