A voiced dialogue node whose voice-over has no lip-sync file.

The engine moves the speaker's mouth from `VO_RESREF.lip`, looked up as any resource: `Override/`, the module's capsules (with its pack `lips/STEM_loc.mod`), and `lips/localization.mod`, which holds the global dialogues' lip sync. Without the file the line plays with the mouth still. A node counts as voiced as for RW1104: it names a `VO_ResRef`, names no `Sound`, and its `SoundExists` is not 0.

```text
note[RW1108]: k_hdroid1_dialog.dlg voice:nm35aadroi01000_ is voiced by nm35aadroi01000_, and no layer holds nm35aadroi01000_.lip
```

This is a note, not a warning: the line still plays, and a speaker with no mouth to move (a droid) needs none. A mod writes its lip sync (`rakata::author::lip::from_cues`) beside its voice-overs.
