A `refs --from` resource the index does not hold.

`rakata refs THING --from` lists what the resource THING refers to, so THING is a resource's name, `name` or `name.ext`, and the index must hold a resource of that name: one of the tree's files or archive members. Names compare without regard to case.

```text
error[RE1507]: the index holds no resource named `k_trg_transfal.ncs`
```

Check the spelling, and that the index was built from the tree that holds it (`rakata index query "SELECT path, member FROM locations WHERE name = 'NAME'"`). Without `--from`, `refs` lists what refers to THING instead.
