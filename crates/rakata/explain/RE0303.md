A value in no form its key takes.

Some keys of a change file take a value of one shape: `RowIndex` a row number, `LogLevel` a number from 0 to 4, the flags (`InstallerMode`, `!ReplaceFile`, ...) 0 or 1, `FieldType` a GFF field type's name or id, `TypeId` a struct type id, a `2DAMEMORY#` key under an `AddColumn` an `I#` or `L#` row. The same code reports an operation that cannot be built because a key it needs is missing: a `ChangeRow` or `CopyRow` without `RowIndex`, `RowLabel` or `LabelIndex`, an `AddField` without a `FieldType`, an `AddColumn` without a `ColumnLabel`.

```text
error[RE0303]: `RowIndex=twelve`: the key takes a row number
error[RE0303]: [heavy_blaster] changes a row without RowIndex, RowLabel or LabelIndex to find it
```

Give the key a value of the shape it takes. An operation missing what it needs stays in the plan as written, so the executor can refuse it rather than guess.
