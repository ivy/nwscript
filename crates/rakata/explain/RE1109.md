A known-findings list for `rakata dialog lint` that does not read.

`--known FILE` names the findings a run accepts: TOML `[[finding]]` tables, each with `dialog` (`NAME.dlg`), `module` (absent for a dialogue of the global layers), `at` (a node `E3` or `R0`, a link `E3>R4`, a start `start>E0`) and `code`. The file could not be read, or is not TOML of that shape.

```text
error[RE1109]: conformance/dialog-known.toml is not a known list: TOML parse error at line 3, column 1
```

`rakata dialog lint --write-known FILE` writes a run's findings in this shape.
