Local variables are shown by index alone: the scripts that name them were not found.

A creature's local booleans and numbers are stored by index (`SWVarTable`). The game names the indices in its include scripts (`int SW_FLAG_AI_OFF = 62;` in `k_inc_generic.nss`); `rakata save show` reads those from the corpus extracted from the user's own game, `nss/k_inc_*.nss` under `$NWSCRIPT_CORPUS`, else `~/.cache/nwscript/corpus/k1`. No names are carried in the tool. When that directory is absent the values are shown by index, and nothing else changes.

```text
warning[RW1201]: local variables are shown by index: no include scripts under /home/you/.cache/nwscript/corpus/k1/nss
```

Extract the corpus with `rakata corpus extract --game DIR`, or point `$NWSCRIPT_CORPUS` at one.
