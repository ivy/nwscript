A field path naming nothing in the file.

The path parses, but following it through the tree fails: a struct has no field of that label, a list has fewer elements than the index asks for, a segment steps into a field that is not a struct or list, or the path ends on a struct where a field was wanted (or the reverse).

```text
error[RE0607]: at `EntryList[3]`: no field `Speker`
error[RE0607]: at `EntryList`: index 40 is past the end of a list of 27
error[RE0607]: at `Tag`: a CExoString field is not a struct
```

The message names how far the path resolved. Check the labels against the file's own, or against the format document for its file type; labels are case-sensitive.
