A blueprint an instance or an inventory names that no layer holds.

`rakata show` reads each instance of an area with its template (`TemplateResRef`, as a `.utc`, `.utp`, `.utd` and so on) and each inventory item with its `.uti`, through the module named with `--module`. No layer holds the blueprint, or it does not read, so what it would say is not shown.

```text
warning[RW2003]: no layer of the install holds k37_plc_gone.utp, or it does not read
```

Without `--module`, a module's own blueprints are not found: name the module. Otherwise the reference is dangling, as `rakata lint` reports it.
