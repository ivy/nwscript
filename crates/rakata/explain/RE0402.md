`chitin.key` names a BIF the install does not hold, and a resource the KEY places in it was asked for.

The KEY's file table lists each BIF by a path relative to the install (`data\2da.bif`), and every resource entry points into one of them. A BIF that is missing is reported only when a resolution reaches it: the KEY shipped with the game names files some platforms do not ship, and an install without them is still an install.

```text
error[RE0402]: `games/swkotor/chitin.key` names `data\templates.bif`, which the install does not hold
```

Restore the BIF from the game's distribution; the install is incomplete, and the engine would fail to load the resource too.
