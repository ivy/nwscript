The index database could not be read or written.

`rakata index` keeps its database in one SQLite file: `--db FILE`, or `index.sqlite` under `$XDG_CACHE_HOME/rakata/` (`~/.cache/rakata/` when the variable is unset). A build loads the file into memory, works there, and writes it back once, to `FILE.partial` beside it and then renamed over it. SQLite or the file system refused one of those steps; the message names the step and SQLite's own reason.

```text
error[RE1501]: loading index.sqlite: file is not a database
error[RE1501]: creating /readonly/rakata: Permission denied (os error 13)
```

A file that is not a database was named by `--db`; name another, or remove it if it is a leftover. A folder that cannot be written needs another `--db`. The database is derived from the game's files and can always be built again.
