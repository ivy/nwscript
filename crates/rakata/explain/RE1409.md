A file the mod writes could not be written.

The authoring API writes a file whole or not at all: to a temporary name beside it, then renamed over it. The operating system refused one of those steps; the message carries its reason. The file the game loads is unchanged.

```text
error[RE1409]: cannot write /games/swkotor/Override/appearance.2da: Permission denied (os error 13)
```

Check that the install's `Override/` and `streamwaves/` are writable, and that the disk has room.
