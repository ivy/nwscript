A member of the save lacks a field the game writes, or holds it with another type.

The readers of `rakata-save` take the fields the game writes into its saves by name: `CatBoolean` and `ValBoolean` in `GLOBALVARS.res`, `PT_MEMBERS` in `PARTYTABLE.res`, `FactionList` in `REPUTE.fac`, a GIT in each module's archive. The member read as a GFF, but the field named is missing or of another type, so the save was written by something other than the game or has been edited.

```text
error[RE1203]: GLOBALVARS.res: `CatNumber` is not a list
```

`docs/formats/save.md` lists the fields each member carries. A save the game itself wrote carries all of them; compare the member with one from an unedited save.
