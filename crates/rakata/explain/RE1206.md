A `rakata save set` assignment does not parse, or its value does not fit the global's type.

An assignment is `NAME=VALUE`, or `NAME=TYPE:VALUE` with `TYPE` one of `boolean`, `number`, `string`, `location`. The global's type comes from the save's own catalogue when it holds the name, else from the install's `globalcat.2da`, else from the prefix; a prefix that disagrees with either is refused, and a name neither holds needs one. Values:

- boolean: `true`, `false`, `1` or `0`
- number: an integer from -128 to 127 (a global number is one signed byte)
- string: any text
- location: six numbers `x,y,z,fx,fy,fz`, the position and the facing

```text
error[RE1206]: `OAJ_DONE=yes`: `OAJ_DONE` is a boolean, written as true, false, 1 or 0
```
