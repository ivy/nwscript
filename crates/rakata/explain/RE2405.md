A name or texture field of the MDL that is not ASCII ended by a NUL.

A binary model's names (the model's, the supermodel's, each node's, each animation's) and each mesh's texture names are ASCII, NUL-ended; the fixed fields are 32 bytes, and every vanilla name fits within them. The field at the offset named holds a byte outside ASCII, or a fixed field has no NUL in its 32 bytes.

```text
error[RE2405]: the node name at model offset 236 is not ASCII ended by a NUL
```

Model offsets count from the end of the 12-byte file header. The model is damaged, or an offset that leads to the name is.
