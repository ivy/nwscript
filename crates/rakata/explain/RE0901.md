Not a LIP V1.0 file.

Every lip-sync file begins with eight bytes naming its kind and version: `LIP V1.0`, the signature `LIP ` (with a trailing space) followed by the version `V1.0`. No other version is known. The file read begins with something else, so it is another kind of file, a version this crate does not know, or not a lip-sync file at all.

```text
error[RE0901]: not a `LIP V1.0` file: the file begins `RIFF$...`
```

Check what the file is. A `.lip` that begins `RIFF` is a WAV misnamed; one that begins `LIP V1.1` would be a version no game shipped. A file shorter than eight bytes is refused with this code too.
