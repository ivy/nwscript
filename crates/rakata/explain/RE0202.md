An archive truncated before its header or tables end.

The header, a table or a string block that the archive's own offsets and counts describe lies past the end of the file: the file was cut short, or the header's numbers are wrong.

```text
error[RE0202]: the resource table at offset 120 for 7040 bytes lies beyond the end of the 4096-byte file
```

Compare the file's size with the size its source has; a download or a copy that stopped early is the usual cause. When the file is one a tool wrote, the tool's header disagrees with what it wrote after it.
