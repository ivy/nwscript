Not a 2DA V2.b table.

Every binary table begins with the nine bytes `2DA V2.b` and a line feed. The file read begins with something else: the text `2DA V2.0` layout of Neverwinter Nights, which KotOR's own files never use, a different format under the `.2da` extension, or not a table at all.

```text
error[RE0701]: not a `2DA V2.b` table: the file begins `2DA V2.0\n`
```

Only the binary layout is read. A text table needs converting first; a file that is not a table should not carry the extension.
