A write into a module's capsule from a mod that names no module.

A write into a module's capsule edits the resource for that module alone, so it needs the module: the mod was opened, or moved with `set_module`, without one.

```text
error[RE1419]: the mod works in no module, so there is no capsule to write tar02_carbast.dlg into; name the module first
```

Open the mod in the module (`Mod::open(install, Some("tar_m02af"))`) or move it there with `set_module` before the write.
