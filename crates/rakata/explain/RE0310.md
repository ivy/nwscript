A script of `[CompileList]` that does not compile.

`rakata install` compiles each script through `nwscript`, as `nws compile` does, with its includes and `nwscript.nss` from the installer's folder first and then from the install; it never runs a compiler the mod ships. The first error is in the message; `nws compile --game-dir GAME -I TSLPATCHDATA SCRIPT.nss` shows them all with their spans.

```text
error[RE0310]: [CompileList] line 5, compile k_fp_heal.nss: k_fp_heal.nss does not compile (1 error): error[E0301]: no function `GetHealTarget`
```

A missing include is the usual cause: the mod expects a file another mod installs first.
