A node whose strref lies past the end of the talk table.

A node's text may name a line of `dialog.tlk` by number. The number is at or past the table's count of strings, so the engine shows nothing for it. A mod that appends lines to the talk table installs the table before the dialogue that uses them.

```text
warning[RW1105]: k_hcar_dialog.dlg strref:99999 shows strref 99999, past the end of the talk table
```

Check the number with `rakata tlk show STRREF --game DIR`.
