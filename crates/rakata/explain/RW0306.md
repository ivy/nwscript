A capsule member whose resref is longer than sixteen bytes, installed under its first sixteen.

A capsule's key table (ERF, MOD, RIM) gives each member's resref sixteen bytes. A `changes.ini` may name a longer file for a capsule, as Sunry Murder Recording Enhancement installs `smre_closesunrydor.ncs` into `modules\manm26ae.mod`; TSLPatcher and HoloPatcher both store it as `smre_closesunryd.ncs`, the first sixteen bytes of the resref and the extension, and `rakata install` does the same and says so.

```text
warning[RW0306]: [InstallList] line 330, Replace smre_closesunrydor.ncs into Modules\manm26ae.MOD: `smre_closesunrydor.ncs`'s resref is longer than a capsule holds; the member is `smre_closesunryd.ncs`
```

The engine looks resources up by sixteen-byte resrefs, so a script that names the longer resref finds the member under the cut name only if the engine cuts the name it is given the same way; the warning is the place to check the mod's references.
