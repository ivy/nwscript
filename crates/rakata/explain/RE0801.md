Not a talk table.

A talk table begins with eight bytes naming its kind and version, `TLK V3.0`, the one version KotOR 1 and 2 ship. The file read begins with something else, so it is an archive or a GFF under the wrong extension, an older talk table version, or not a talk table at all.

```text
error[RE0801]: not a `TLK V3.0` talk table: the file begins `RIM V1.0`
```

Check that the path names `dialog.tlk` (or a module's alternate table) and not a resource with a similar name. A pre-3.0 table, which has no sound-length field, is not read.
