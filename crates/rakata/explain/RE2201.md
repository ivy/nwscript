A TPC truncated before its header or pixel data ends.

A TPC is a 128-byte header, then the pixel data, then optional TXI text. The header's size, pixel format and mip count fix the length of the pixel data: each mip level of each image (one, six cube faces, or the frames of an animation sheet) in turn. The file read is shorter than the header, or shorter than the header and the pixel data it describes.

```text
error[RE2201]: the TPC's pixel data needs 87536 bytes and the file has 65664
```

The file was cut short in copying or extraction, or its header is damaged. Re-extract it from its archive (`TexturePacks/*.erf` for the game's own).
