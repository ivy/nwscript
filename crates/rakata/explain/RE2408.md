A controller whose keys lie past its node's controller data.

A node's controllers (its position, orientation and other keyed properties) are 16-byte records, each giving a row count, the index of its first time key and the index of its first value in the node's array of controller data floats. The controller named claims rows whose time keys or values run past the end of that array.

```text
error[RE2408]: node `rootdummy`'s controller of type 8: its values at float 1 run 9 floats and the node's data has 4
```

The model is damaged. In every vanilla controller the time keys and the values lie inside the node's data, the values right after the times.
