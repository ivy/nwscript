A 2DA row with more or fewer cells than the table has columns.

The file stores one offset per cell, rows times columns, so a row must have exactly one cell per column. A row of the table being written has another number: its cells were edited directly rather than through the table's methods, which keep every row the width of the column list.

```text
error[RE0709]: row 4 has 5 cells where the table has 4 columns
```

Give the row one cell per column, blank cells as empty strings.
