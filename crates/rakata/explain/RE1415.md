Another module's own copy of a resource that a write to `Override/` would replace, unlike the copy the mod edits.

`Override/` outranks every module's capsules, so a file written there replaces the resource in every module that loads it, not only the one the mod works in. A module that holds its own copy, different from the one the mod read and edited, would lose what that copy does: two areas may each carry their own conversation of one name, as Taris's two cantinas carry their own `tar03_cand031.dlg`.

```text
error[RE1415]: tar_m03ae_s.rim holds tar_m03ae's own tar03_cand031.dlg, which is not the copy tar_m02ae loads; written to Override, the edit would replace it in tar_m03ae too
```

Make the edit to one copy that serves every module, or leave the resource alone and reach the scene another way (a new conversation of the mod's own name).
