A TGA run-length packet past the image's last pixel.

A run-length encoded TGA stores its pixels in packets, each a count byte and then one pixel repeated or that many pixels raw. The packets must cover exactly width × height pixels. In the file read, a packet runs past the last pixel.

```text
error[RE2206]: a TGA run of 128 pixels at pixel 4000 passes the image's 4096
```

The encoder that wrote the file let a packet cross the end of the image, or the header's size is wrong. Save the image again, uncompressed if the tool allows.
