A blueprint field set to a value of another type.

The engine reads each field of a blueprint by the type its format document gives (`Str` a `BYTE`, `HitPoints` a `SHORT`), so a field keeps its type when a mod sets it. The value given is of another type.

```text
error[RE1406]: HitPoints holds a SHORT, and the value given is a WORD
```

Give the value in the field's own type; `rakata gff show FILE --path FIELD` prints it.
