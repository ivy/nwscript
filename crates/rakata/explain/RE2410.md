A supermodel chain that comes back to a model it has passed.

A model names a supermodel whose animations and nodes it inherits, and that model may name its own. Following the names from the model asked for reaches a model already in the chain, so the chain would never end.

```text
error[RE2410]: the supermodel chain a -> b -> A comes back to a model it has passed
```

Names compare without case. No vanilla chain loops; the deepest passes seven supermodels. A mod that renames a model or its supermodel can make one.
