The loader failed reading a model of a supermodel chain.

Loading a model's supermodel chain asks the caller's loader for each model by name. The loader returned an error for the model named, rather than its bytes or word that there is no such model; the loader's own message follows.

```text
error[RE2411]: reading model `s_male02` of a supermodel chain: the BIF `data/models.bif` is not readable
```

The cause is the loader's: an install that cannot be read, a damaged archive. A supermodel the install simply lacks is not this error; the chain stops there and names it.
