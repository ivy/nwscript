An index database of another schema version.

The index records its schema's version in its `meta` table under `schema`. A build of `rakata` reads only databases of its own version, since a table or column the queries and lints expect may be missing or mean something else in another.

```text
error[RE1502]: `index.sqlite` holds an index of schema 0; this build reads schema 1: build it again into a new file
```

Build the index again, cold, into a new file (or remove the old one): `rakata index build --game DIR --db FILE --tree LABEL`. The database is derived from the game's files, so nothing is lost. `docs/index.md` describes the current schema.
