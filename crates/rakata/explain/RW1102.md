A script or condition that no layer of the install holds.

A node's `Script` or a link's `Active` names a script the engine cannot find: not in `Override/`, the module's capsules, `patch.erf` or the BIFs. The transcript prints it `[missing]`.

```text
warning[RW1102]: dan14_cutjuh.dlg names the script k_con_juhani, which no layer of the install holds
```

Module scripts are found only with the module named: `rakata dialog show NAME.dlg --module STEM --game DIR`. A dialogue read from a file outside the install needs `--module` for the same reason.
