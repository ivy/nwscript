A file an install operation edits that does not parse as its format.

The bytes the operation started from (from the destination, the installer's folder or the game) are not a 2DA, GFF, talk table, soundset or capsule of the kind the list edits. The message names where the bytes came from and what the format's reader found.

```text
error[RE0308]: [2DAList] line 12, ChangeRow0 on appearance.2da: Override/appearance.2da does not read as a 2DA: not a 2DA V2.b table
```

A text 2DA in `Override` (the `2DA V2.0` form some tools write) is the usual cause; convert it to the binary form the game ships.
