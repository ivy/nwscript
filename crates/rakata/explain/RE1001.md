A file of the corpus could not be written.

`rakata corpus extract` and `rakata corpus decompile` write under the corpus directory: `--out DIR`, else `$NWSCRIPT_CORPUS`, else `~/.cache/nwscript/corpus/k1`. Each run removes the subtree it owns (`nss/`, `ncs/`, `oracle/`, `modules/`, `rims/` for extract; `decompiled/` for decompile) and writes it again, so a rerun is byte-identical. The operating system refused one of those writes: the directory is not writable, the disk is full, or a path component exists as a file.

```text
error[RE1001]: cannot write /home/you/.cache/nwscript/corpus/k1/decompiled/danm14ac_s/k_pdan_juhani27.nss: Permission denied (os error 13)
```

Pick a writable `--out`, or fix the permissions of the corpus directory. The corpus is derived from the game's bytes and belongs under the user's cache, never in a repository.
