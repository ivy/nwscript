An output file could not be written.

A command that writes a file (`rakata gff set -o OUT`, `rakata tlk append -o OUT`, `rakata cat -o OUT`) could not create or write the path it was given. The message carries what the operating system said.

```text
error[RE1306]: cannot write `out/dan14_juhani.utc`: No such file or directory
```

Check that the folder exists and is writable, and that the disk has room.
