Bytes written as NCS that do not decode.

The authoring API reads every file back as its type before writing it. A file named `.ncs` must be NWScript bytecode: the `NCS V1.0` header, the size record, and instructions to its end. These bytes are not; the message carries the decoder's reason.

```text
error[RE1414]: k_oaj_bad.ncs is not NCS bytecode: not an NCS V1.0 file
```

Write the bytes the authoring API's `scripts::compile` returns, or `nws compile`'s output.
