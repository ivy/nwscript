A resource that does not read as its format, compared by hash.

The diff compares each pair of files or members whose bytes differ by its format, chosen by extension: GFF by field path, 2DA by row and column, the talk table by strref, a dialogue by node, a LIP by keyframe, a texture by header, level and TXI instruction, a layout or visibility file by room, a walkmesh by material and transition, a model (its MDL and MDX read together) by node and animation, an archive by member. One side of this pair did not read as that format, so its contents were not compared: the entry shows the two hashes and is marked "contents not compared", and the diff goes on.

```text
warning[RW1601]: `Override/broken.utc` does not read as gff: B: RE0602: ...; compared by hash
warning[RW1601]: `Override/c_rancor.mdx` does not read as mdl: no MDL of its name lies beside it to read it with; compared by hash
```

An MDX is read with the MDL of its name: beside it in its folder or archive, or, for an Override file, the one the install loads. The message names the side (A or B) and the reader's own error, whose code `rakata explain` covers. A file a mod tool wrote that the engine accepts and the reader refuses is a defect in the reader; `rakata conformance` over the tree shows every such file.
