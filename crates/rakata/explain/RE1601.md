A diff of a directory against a file.

`rakata diff A B` compares two trees, or two resources. Two directories are trees: their files are paired by path, in any case, and each pair compared by its format. Anything else is a resource: a file on disk, an archive (its members are compared), an `ARCHIVE!MEMBER`, or a `NAME.EXT` the install `--game` names resolves. One side was a directory and the other was not, so there is nothing to pair the directory's files with.

```text
error[RE1601]: `ckpt/a/tree` is a directory and `dan14_juhani.dlg` is not: a diff compares two trees or two resources
  = help: name two directories to compare trees, or two files, archive members or resources
```

To compare one file of a tree with another file, name the file inside the tree: `rakata diff ckpt/a/tree/Override/dan14_juhani.dlg ./dan14_juhani.dlg`. To compare two trees but only some of their paths, name the trees and narrow with `--only`.
