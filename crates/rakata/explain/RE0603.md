A GFF struct, field or label index out of range.

A struct's field list names fields by their position in the field array, a field names its label by position in the label table, and a `Struct` or `List` field names structs by position in the struct array. One of these positions is past the end of its array, or a struct is reached from two places (which would make the tree a graph, and a cycle would never end). A file with no structs at all is reported the same way, since every GFF has a root.

```text
error[RE0603]: field index 2267 is out of range: there are 2267
error[RE0603]: struct (reached twice) index 14 is out of range: there are 260
```

The file was written wrongly; the engine would read garbage or crash on it. Rewrite it from its source.
