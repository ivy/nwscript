A memory token read during the install that has no value.

`2DAMEMORY#` takes its value from an earlier `2DAMEMORY#=RowIndex` (or a column, a `ListIndex`, a `!FieldPath`) and `StrRef#` from the `[TLKList]` append. When the operation that would set it failed, or nothing sets it, the reading operation cannot apply. `RW0304` reports the same token from the plan, before anything runs; this is the install meeting it.

```text
error[RE0311]: [GFFList] line 40, edit tat_senni.utc: 2DAMEMORY1 is read, and no operation before this one stored it
```

Fix the operation that should have set the token (its own error is earlier in the report), or add the store.
