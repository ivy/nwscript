A lip-sync file truncated before its header or keyframes end.

A lip-sync file is a 16-byte header (signature, version, the line's duration, the keyframe count) followed by exactly that many keyframes of 5 bytes each, so its length is 16 + 5 × count. The file read is shorter than that: either it ends inside the header, or the count at offset 12 promises more keyframes than the bytes hold.

```text
error[RE0902]: the keyframes need 1216 bytes and the file has 1200
```

The file was cut short in copying or extraction, or its count is wrong. Re-extract it from its archive; if the count is the problem, the file is damaged and the keyframes it does hold cannot be told from the ones it lost.
