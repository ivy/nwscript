A model structure the owned model does not hold.

`rakata_mdl::ModelFile` holds every structure of a binary model it knows the length of: dummies, lights, emitters, references, and meshes as trimeshes, skins, dangly meshes, AABB walkmeshes and lightsaber blades. A node whose flags word names another kind (the NWN animmesh, 0x0A1, or a value no vanilla model carries) has a header of unknown length after its node header, so the model cannot be read into this form or written; an MDX block on a node of an animation is refused for the same reason.

```text
error[RE2414]: not a structure this crate holds: node flags 0x0a1 at model offset 1416
```

The reader `rakata_mdl::Model` still reads such a model's other nodes. No vanilla KotOR 1 model has one.
