A `File#` entry skipped because its destination holds the file.

Under `[InstallList]` and `[CompileList]`, `File#=NAME` copies only when the destination does not have `NAME` yet, and `Replace#=NAME` overwrites. TSLPatcher logs the skip as a warning ("A file named X already exists in the override folder. Skipping file..."), and `rakata install` reports it the same way; the report records the hash of the file that stayed.

```text
warning[RW0305]: [InstallList] line 9, File0 k_x.ncs into Override: Override/k_x.ncs exists; `File#` does not overwrite it
```

When the mod's copy must win, the entry should be `Replace#`.
