A tree without nwscript.nss: calls name routines by number.

A script's engine calls are read from its bytecode, where an `ACTION` names its routine by number; the tree's own `nwscript.nss` (in `scripts.bif`, or `Override/`) gives each number its name and parameters. The tree holds none, so every call is recorded as `routine_N`, vector arguments are not read as literals, and no argument is classified as a reference.

```text
warning[RW1503]: `trees/partial` holds no nwscript.nss: calls name their routines by number
```

Index a complete install. The `calls` table's `routine_id` column holds the number either way.
