A 2DA too large for its 16-bit string offsets or 32-bit row count.

The layout stores each cell as a two-byte offset into the strings and the strings' length in two bytes, so the distinct strings of a table, each with its NUL, cannot exceed 65,535 bytes; the row count is four bytes. The table being written needs more.

```text
error[RE0704]: the strings come to 65540, more than the 65535 the layout holds
```

Identical strings are already stored once, so the limit is on distinct values. Shorten or share values, or split the table, if the game will accept that; the layout itself allows nothing larger.
