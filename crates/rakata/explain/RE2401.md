Not a binary model: the MDL's first word is not zero.

A binary MDL begins with a 12-byte header whose first four bytes are zero, then the size of the model data and the size of the MDX. The file read begins with something else. An ASCII model (text beginning with a comment or `newmodel`) is refused with this code, as is any other kind of file given as a model.

```text
error[RE2401]: not a binary model: the first word is 0x414d2023, not zero
```

Check what the file is. An ASCII model must be compiled to the binary form before the game, or this reader, can use it. The layout is `docs/formats/mdl.md` of the rakata repository.
