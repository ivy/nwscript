A talk table string holding a character Windows-1252 cannot encode.

KotOR stores the talk table's text in Windows-1252, one byte per character: ASCII, the Latin-1 letters and symbols, and the typographic quotes, dashes and ellipsis the code page places at 0x80 to 0x9F. The text of one entry holds a character outside that set, so there is no byte to write for it.

```text
error[RE0803]: the text of strref 49361 holds 'Ж' (U+0416), which Windows-1252 cannot encode
```

Replace the character with one the code page has, or transliterate it. A text read from a game file never fails here: every byte of the file decodes to a character that encodes back to the same byte, including the five bytes the code page leaves undefined.
