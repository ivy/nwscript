A member replaced that the archive does not hold.

Replacing a member means giving the member of that name and type new bytes. The archive holds none, so there is nothing to replace; a silent add would hide a misspelt name or a wrong archive.

```text
error[RE0207]: the archive holds no k_pdan_juhani31.ncs; add it instead
```

Check the name and the type (the extension), and that this is the archive meant: a module's scripts live in `STEM_s.rim`, not `STEM.rim`. Use add when the member is new.
