A path a Lua script reads or writes that is not one of its inputs.

`rakata lua` runs a script hermetically: its inputs are its arguments and the install `--game` names, and nothing else. `rakata.fs.read`, `rakata.fs.exists`, `rakata.fs.list` and a dialogue session's `load` of a file read only below `--game`, the script's own directory, and the paths the script's arguments name; `rakata.fs.write` writes only below `--game` and the arguments' paths. A path is compared after `.`, `..` and symbolic links are resolved, so a link cannot lead out of a named directory.

```text
error[RE1801]: `/etc/passwd` is not one of the script's inputs: a script reads only below --game, its own directory, and the paths its arguments name
```

Pass the file or a directory holding it as an argument (`rakata lua build.lua OUT --game DIR`) and build the path from `rakata.args`.
