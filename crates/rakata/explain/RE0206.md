A member added under a name the archive already holds.

Adding a member means the archive did not hold one of that name and type, compared as the engine compares names, without regard to case. It does, so the operation would leave two members with one name, and the engine's choice between them is not established.

```text
error[RE0206]: the archive already holds k_pdan_juhani31.ncs; replace it instead
```

Use replace to give the existing member new bytes. A `changes.ini` that says `Replace#=` means exactly this; `File#=` into an archive that already holds the name is the ambiguous case.
