An install operation that cannot apply as written.

The operation names a row, column, field, talk-table entry, byte offset or soundset sound that the file does not have, or gives a value in a form the target cannot hold: text in a numeric field, a number too wide for the field, a struct added to a list without being a struct. A 2DA operation that fails leaves the table as it was; the other operations on the same file still apply, and the file is written with them.

```text
error[RE0309]: [2DAList] line 20, ChangeRow3 on baseitems.2da: row 400 does not exist; the table has 92 rows
error[RE0309]: [GFFList] line 44, edit tat_senni.utc: line 47: `Appearance_Typo`: no field `Appearance_Typo` in the root struct
```

Correct the row, label or path in the changes file against the file it edits (`rakata which NAME --game DIR` finds the copy the game loads).
