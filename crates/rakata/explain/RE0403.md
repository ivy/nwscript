No capsule under `modules/` carries the module name given.

A module is named by the stem its capsules share: `danm14ac` for `danm14ac.mod`, `danm14ac.rim` and `danm14ac_s.rim`. A capsule file name is accepted and its suffix dropped, and case does not matter. The name must match at least one capsule in the install's `modules/` folder.

```text
error[RE0403]: no capsule named `danm14` under `games/swkotor/modules`
```

List the folder to find the stem; the area's name in the game (`Dantooine - Courtyard`) is not the module's.
