A script whose bytecode the decompiler could not read.

`rakata corpus decompile` recovers every NCS it finds in the module capsules, under `rims/` and under `Override/`. This one did not decode as NCS V1.0, or decoded with no entry point the decompiler recognises (`JSR main; RETN` after the globals), so no source is written for it. The run goes on; the script counts as failed in the report and the warning names it.

```text
warning[RW1001]: modules/danm14ac_s.rim:broken.ncs: not an NCS V1.0 file
```

`nws disasm FILE` shows what the bytes are. A capsule member with the `.ncs` type that is not a script, or a file truncated by the tool that wrote it, is the usual cause; the engine would fail on it too.
