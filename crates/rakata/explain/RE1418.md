A copy in `Override/` that a write into a module's capsule would stay beneath.

`Override/` outranks every module's capsules, so while it holds a resource the module goes on loading that copy, and a version written into the module's `.mod` is never read. The copy may be another mod's, or one this mod wrote to `Override/` earlier.

```text
error[RE1418]: Override holds tar02_carbast.dlg (Override/tar02_carbast.dlg), which outranks tar_m02af's capsules; written into tar_m02af.mod, the edit would never be loaded
```

Edit the copy in `Override/` instead, if every module may load the edit, or find out which mod put it there and whether the module still needs it.
