Text for a new node holding a character Windows-1252 cannot encode.

KotOR stores a dialogue's strings in Windows-1252, the game's code page, and has no glyph for a character outside it. A new node's text, speaker, listener, comment or an animation's participant holds a character that code page has no byte for, such as an emoji.

```text
error[RE1108]: `☺` in a node's Text has no Windows-1252 byte, the game's code page
```

Use a character the code page holds; its curly quotes and dashes are among them.
