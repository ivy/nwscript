A model read without its MDX.

A binary model is two files of one name: the MDL, its header and node tree, and the MDX, the vertex data of its meshes. `rakata mdl show` looks for the MDX the way the MDL was found: through the install for a `NAME.mdl`, in the same folder for a path, in the same archive for a member. None was there, so the model is read from its MDL alone.

```text
warning[RW1302]: `models/box.mdl` has no MDX beside it: the model is read without vertex data
```

A model without meshes needs no MDX and reads in full. A model with meshes then fails with RE2403, its vertices past the end of an empty MDX; put the MDX beside the MDL, under the same name.
