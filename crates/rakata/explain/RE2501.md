Not a walkmesh: the bytes do not begin `BWM V1.0`.

An area room's WOK, a placeable's PWK and a door's DWK share one binary layout, which begins with the eight ASCII bytes `BWM V1.0`. Every vanilla walkmesh does. The file read begins otherwise, so it is another kind of file, empty, or an ASCII walkmesh as a model compiler takes it rather than the compiled form the game ships.

```text
error[RE2501]: not a walkmesh: the bytes do not begin `BWM V1.0`
```

Check what the file is. The layout is `docs/formats/walkmesh.md` of the rakata repository.
