A resource id without the `.ext` that names its type.

A resource is identified by its name and its type together, written `name.ext`, as in `k_act_com1.ncs` or `banter.dlg`. The same name can exist with several types, so the name alone does not say which resource is meant.

```text
error[RE0102]: resource id `k_act_com1` has no `.ext` naming its type
```

Add the extension of the type you mean: `.ncs` for compiled scripts, `.nss` for their source, `.dlg` for dialogues, `.utc` for creature blueprints, and so on.
