A `refs` query that found nothing, qualified by what the index could not search.

An empty answer means that no resource the index read names the symbol. Resources the index has no reader for (textures, models, walkmeshes, sounds, lip-sync files) and resources a reader rejected are located and hashed but not read, so a reference inside one of them cannot be found. The warning counts them, so the absence is stated with its limits.

```text
warning[RW1505]: no reference to `k_nothere` (tried resref, tag, global); the index could not search 57011 resources: no reader for 57011 (lip 18432, tpc 13562, ...), 0 failed
```

Check the spelling and the kind; `--kind auto` tries every kind the symbol can be. `rakata index coverage --list` names every resource without a reader.
