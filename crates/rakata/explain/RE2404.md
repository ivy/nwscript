The node tree reaches a node twice, or a node's number names no name.

A binary model's nodes form a tree: the root's offset is in the header and each node lists its children's offsets. Each node's number indexes the model's name array. The model read either reaches some node a second time (a cycle, or two parents sharing a child), or has a node whose number is past the end of the name array.

```text
error[RE2404]: node tree: the node at model offset 2722 is reached twice
```

The model is damaged, or was written by a tool that does not produce the game's layout. Re-extract it, or rebuild it from its source.
