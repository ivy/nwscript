A directory that is not a game install.

Every command that reads the game takes `--game DIR`, the folder holding `chitin.key`: the KEY that indexes the BIFs under `data/`, beside `dialog.tlk`, `modules/`, `Override/` and the other folders the engine reads. The directory named has no `chitin.key` in any case, so it is a folder inside the install, a folder above it, or not an install at all.

```text
error[RE0501]: `games/swkotor/modules` is not a game install: it has no chitin.key
```

Pass the install's root. On a Steam install that is the `swkotor` folder itself; a modded build in the same layout works the same way.
