A resource of a type the inspection command does not read.

Each inspection command reads the formats of one crate, and tells by the resource's extension which it is: `rakata texture show` reads `.tpc`, `.txi` and `.tga`; `rakata lyt show` reads `.lyt` and `.vis`; `rakata walkmesh show` reads `.wok`, `.pwk` and `.dwk`; `rakata mdl show` reads `.mdl`, or an `.mdx` with its `.mdl` beside it. The resource named has another extension, or is an MDX whose MDL is not found the way the MDX was.

```text
error[RE1307]: `Override/lhr_flr01.dds` is a .dds, which `rakata texture show` does not read
  = help: `rakata texture show` reads a .tpc, .txi or .tga
error[RE1307]: `models/box.mdx` is an MDX with no MDL beside it
```

Name the resource with its own extension, and run the command for its format; `rakata gff show` reads any GFF and `rakata cat` any resource's bytes.
