A count or coordinate of a layout or visibility file that is not a number.

A layout's counts are whole numbers from zero, its coordinates and quaternion components are decimal numbers (`39.4685`, `-0.0407561`, `9.76562e-006`), and a door hook's third field is an integer. A visibility file's room line ends with the count of rooms it sees. The token named does not read as such a number, or reads as one that is not finite (`nan`, `inf`).

```text
error[RE2303]: line 7: `1,5` is not a finite number
```

The vanilla files write numbers with a point for the decimal separator, never a comma; a tool that wrote this file under a locale that uses commas would produce the line shown.
