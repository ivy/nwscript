A voiced node whose voice-over no layer or `streamwaves/` holds.

A node's `VO_ResRef` names the WAV the engine plays while the line shows, found under `streamwaves/` or `streamvoice/` (in any subfolder) or in the resource layers. No file of that name exists, so the line plays silent. A node counts as voiced only when its `SoundExists` is not 0 and it names no `Sound`: BioWare's tool writes 0 on the lines it has no recording for (the player's replies name placeholders such as `_m13aabast01001_`), and a node with a `Sound` plays that instead (a Wookiee's speech, `n_gwwook_comm1`, under a `VO_ResRef` never recorded). The vanilla game has no voiced node without its file.

```text
warning[RW1104]: oaj_banter.dlg voice:oaj_mis21 is voiced by oaj_mis21, and no layer or streamwaves/ holds oaj_mis21.wav
```

A mod writes its voice-overs (the authoring API's `write_streamwaves`) before the dialogue that plays them.
