A voiced node whose voice-over no layer or `streamwaves/` holds.

A node's `VO_ResRef` names the WAV the engine plays while the line shows, found under `streamwaves/` or `streamvoice/` (in any subfolder) or in the resource layers. No file of that name exists, so the line plays silent. BioWare's own dialogues hold some: unrecorded lines carry a resref the game ships no file for, often with a leading underscore.

```text
warning[RW1104]: oaj_banter.dlg voice:oaj_mis21 is voiced by oaj_mis21, and no layer or streamwaves/ holds oaj_mis21.wav
```

A mod writes its voice-overs (the authoring API's `write_streamwaves`) before the dialogue that plays them.
