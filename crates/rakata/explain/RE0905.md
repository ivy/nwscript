More keyframes than a lip-sync file's 32-bit count holds.

The header stores the keyframe count as an unsigned 32-bit integer, so a file holds at most 4,294,967,295 keyframes. A track built in memory with more than that cannot be written.

```text
error[RE0905]: 4294967296 keyframes exceed the format's 32-bit count
```

No voice line needs anything near this many; a track this long comes from a loop that never stopped adding cues. Check the cue source.
