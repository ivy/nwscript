A file of the tree that could not be read.

The build lists the tree's files and reads each one it does not carry over from a parent. A file could not be opened or read; it has a `coverage` row with the status `failed` and the reason, and no location.

```text
warning[RW1502]: 1 file(s) of the tree could not be read, such as `Override/locked.tga`: Permission denied (os error 13)
```

Fix the file's permissions or the dangling link and build again. `rakata index coverage --db FILE --list` shows every row with its status.
