A strref the talk table does not hold.

`rakata tlk show STRREF` looked the number up in the talk table, and the table has fewer entries, or the value is `-1` (`4294967295`), which refers to no string.

```text
error[RE1304]: the talk table holds 49265 entries; strref 52000 is not one of them
```

Check the number. A strref of a module's alternate table (bit 24 set) is looked up by its low 24 bits here. A strref a mod adds is in the `dialog.tlk` of the install it was installed into: name that install with `--game`, or the file with `--from`.
